# Delta1 券源工作台 · 原生桌面 App

Python + PySide6 原生 Windows 应用，默认入口为 python -m securities_lending。界面按公司 1920×1080 屏幕设计，支持 Windows 放大显示、小窗口横向滚动和可收起的券源明细。默认启动不打开浏览器。

后续对话或继续开发，请先读 [项目交接与后续修改入口](PROJECT_HANDOFF.md)：包含已确认业务口径、代码索引、最近修复、验证边界和继续工作流程。

**公司使用 `codex/company-apps`，在仓库根目录一次 `git pull --ff-only` 更新券单、基差和指数策略等全部已发布模块。** `codex/securities-lending` 用于开发；公司运行时保持统一分支。

持续开发约定见 [AGENTS.md](AGENTS.md)：每次修改后更新 PROJECT_HANDOFF.md，完成验证，将本次代码、测试和说明提交推送到开发分支，再将本次已验证提交汇总、验证并推送到 `codex/company-apps`，保留其他模块及本机数据。

## 日常启动和查询

1. 在 swhy_delta1 环境中双击 securities_lending/start.cmd；家中使用 start_demo.cmd。环境说明见 [COMPANY_SETUP.md](COMPANY_SETUP.md)。
2. 首次打开「设置 → 券单来源」，选择公司的「发送券单」根目录。
3. 每次启动按**北京时间运行日期**优先校验并读取当日本地券单；已有有效副本时**不访问公盘、不重新下载**。无可用副本时才从「根目录 / YYYY-MM-DD / 申万内部券单YYYY-MM-DD.xlsx」完整下载并校验，再读取本地副本的“库存券单”Sheet。公盘盘中更新后，点击「同步当日券单」或按 F5 强制获取新版本。
4. 输入代码或名称，按 Enter 查询。逐票显示名称、完整代码、识别和库存状态；券单外代码通过 Wind 补名称，券单外名称检索当日 A 股目录。名称优先精确匹配，再包含匹配，按完整代码汇总其全部券源并去重。**零库存和券单无记录均高亮“库存没有”**；证券身份未确认、券单不可用、数量缺失会分别说明，不把查询失败当成零库存或证券不存在。
5. 每行选择**金额 / 万元**或**数量 / 股**，在黄色输入框填写要求。停止输入 0.9 秒后自动重新请求 Wind 行情并计算；也可点击「刷新价格并计算」或按 Ctrl+Enter 立即执行。编辑后旧结论立即失效，刷新完成前不可复制/导出。切换单位会清空该行输入，防止把原金额误当成股数。
6. 每只股票旁显示自有是否覆盖、其他来源是否单独足够或能够补足、自有/其他上限，以及合计最大股数和大致金额。数量不足时保留原需求。下方明细默认展开，可拖动中间分隔条放大；费率、股数、行业和最新价加粗，价格字号大于时间。
7. 「打开下载位置」直接打开本次下载 Excel 的批次目录，即使文件读取失败也可定位；本次未下载时打开正在使用的缓存目录，均无文件时才打开本模式数据目录。「文件与同步详情」提供实际文件名、共享来源、本地路径、要求/实际 Sheet（缺失时）、下载/检查时间、大小与 SHA256，并可「复制全部详情」或「打开本地 Excel」。

仓库根目录命令：

~~~powershell
python -s -X utf8 -m securities_lending
python -s -X utf8 -m securities_lending --demo
~~~

演示模式始终使用合成券单与价格，不访问公司共享盘、不调用 Wind，窗口有固定演示标识。演示设置独立保存到 data/demo/config.local.json，即使正式配置损坏也可启动演示。正式/演示缓存和导出模式均有区分。

## 已确认的默认业务口径

默认列名依据用户提供的申万库存券单结构，匹配列名而非固定字母位置。所有列名都可在「设置 → 列名映射」逐项修改。

| 用途 | 默认 Excel 列名 | 处理 |
| --- | --- | --- |
| 代码 / 名称 | 证券代码 / 证券简称 | 支持沪深北代码、前导零和交易所后缀 |
| 可融股数 | 可融股数 | 默认与实际可融股数逐笔比较 |
| 实际股数 | 实际可融股数 | 两列取较小值，保留各自原值 |
| 费率 | 参考费率 | 普通数值 0.05 显示 5%，不假定年化 |
| 期限 / 来源 | 期限 / 来源 | 每笔分别保留 |
| 原始市值 / 上限 | 可融市值 / 可融市值上限 | 仅作追溯参考，不参与当前估值和需求换算 |
| 券单价格 | 收盘价 | 参考字段，不替代 Wind 最新价 |
| 行业 | 自动识别 | 缺失时由 Wind 补充，默认申万一级 |

~~~text
单笔有效库存 = min(实际可融股数, 可融股数)
标的有效库存 = 同一证券各笔有效库存之和
最大可借股数 = floor(标的有效库存 / 100) × 100
库存市值（元） = 标的有效库存 × Wind 本次有效最新价
需求股数 = floor(目标名本（万元）× 10000 / 最新价 / 100) × 100
取整名本 = 需求股数 × 最新价
未用名本 = 目标名本（元）− 取整名本
~~~

- 从 Excel 数量/金额解析、单位换算到汇总和取整均使用 Decimal，0.57 万股准确转换为 5700 股。
- **先逐笔取小值再汇总**，不能改成两列分别合计后取小值。主表显示有效库存和整百股上限，悬停库存可查看两列原始合计，展开明细可查看每笔原值。
- 任一笔必要数量列缺失/无效，汇总仅显示已知数量并标记“已知”，不确认整个标的的可借上限或完整库存市值。
- 超过库存时显示“库存不足”、需求股数和上限，不静默缩减后显示成功。
- 金额输入沿用整百股向下取整；直接输入股数须为 **100 的正整数倍**，不默默取整。股数输入可以在价格不可用时仅校验数量，但金额显示无法估算；金额输入没有有效价格时不能换算。
- 自有上限按来源去空白后恰好等于“互换”的行汇总；其他来源单独汇总，仅判断券单数量是否单独足够或可补足。**不自动认定其他来源归属，不推断券单外交易台库存，不自动分配费率/期限**；需要其他来源时明确提示“需询券”。任一必要库存数量缺失时仍不确认合计上限。
- **库存市值（按最新价）**、**输入的目标名本**和**券单原始市值（仅参考）**是不同字段。没有本次有效价格时，估值和换算不可用；不得用旧行情或券单收盘价替代。
- 同一标的多笔券源显示费率范围，各笔费率、期限、来源不合并成平均费率。
- 可以在设置中切换“仅使用可融数量列”，适配单列库存模板；默认仍采用两列较小值。
- 单元格显式单位优先于表头，表头优先于设置。支持股/万股、元/万元/亿元。百分比格式与带百分号文本自动识别；普通数字默认小数费率口径，其他模板可切换。
- 原始券单市值只供参考。旧模板缺少原始名本但有券单价格时，参考明细可保留明确标记的券单估算值，不作为主表最新估值。

## 批量输入、编辑和复制

「批量粘贴…」（Ctrl+B）支持一列代码/名称，也支持从 Excel 复制两列：**代码/名称 + 目标名本（万元）**。两列使用制表符分隔，可带“证券代码”“目标名本（万元）”表头；每次最多 100 项输入。

第二列为空时保留已填金额。带金额的名称必须唯一匹配，未匹配或匹配多只时提示改用完整代码；多个输入指向同一股票但金额冲突时，整批拒绝应用。

在表格输入框内还可粘贴一列数值，从当前行向下按各行所选单位填写；存在无效金额/股数或超出表尾时整列不应用。两列批量粘贴仍固定为金额（万元），会替换相应行原有的股数模式。

| 操作 | 快捷键 |
| --- | --- |
| 聚焦查询框 | Ctrl+L |
| 查询 | 查询框 Enter |
| 下一只股票 | 名本框 Tab / Enter / ↓ |
| 上一只股票 | 名本框 Shift+Tab / ↑ |
| 重新获取价格并计算 | Ctrl+Enter |
| 多选表格行 | Ctrl / Shift + 点击 |
| 选择全部表格行 | 表格 Ctrl+A |
| 复制所选行，含表头、单位、状态和来源 | 表格 Ctrl+C |
| 导出 | Ctrl+E |
| 同步当日券单 | F5 |

输入框内 Ctrl+C 仍复制选中文字。点击名本框时，当前股票与明细同步。上表按股票显示合计股数；选中有库存明细的股票时，下方自动展开**逐笔券源表**，每笔分别列出来源、期限、费率、有效库存、两列原始股数、文件及 Excel 行号，不合并不同费率或期限。上表的费率区间仅供概览，不是合并成交费率。

来源为 **“互换”** 的行标记为 **“自有券源，无需询其他交易台”**，仍保留原始来源值；这不改变数量校验、费率或期限。其他来源不自动判断归属。汇总库存不代表已按某个费率/期限分配需求。

「券源明细」可展开/收起，主表与明细之间的分隔条可上下拖动；无库存标的也能查看单独结论。「复制明细」复制选中券源行，未选行时复制当前股票全部明细，也可在明细表按 Ctrl+C。「计算与追溯」查看完整价格时间、识别来源、自有缺口/合计缺口、计算依据和快照路径。列宽可拖动调整，窄窗口用水平滚动条查看其余列。

## 导出与来源追溯

默认导出 Excel，包含“查询汇总”“券源明细”“数据说明”；也支持 CSV 汇总或 CSV 券源明细。CSV 使用 UTF-8 BOM，复制内容使用制表符分隔。

导出包含：正式/演示模式、库存日期和状态、下载时间、本次价格和来源/时间、目标名本、需求、整百股上限、校验通过股数、取整名本和余量、最新库存市值、两列原始股数、原始券单市值/上限，以及逐笔费率、期限、来源、券源说明（互换=自有）、文件名、Excel 行号、本地快照和 SHA256。汇总表也单独列出券源笔数、逐笔期限及来源。

CSV 汇总也有逐笔追溯文本。金额/原始数量保留精确值，Excel 超出可精确表示范围的数值用文本保存。库存不足时“校验通过股数”为空。原生保存对话框可另选位置，默认在项目 data/exports；导出在后台完成，先写临时文件，成功后才替换目标，失败不损坏已有导出。

汇总复制/导出同时保留标的识别及来源、库存提示、金额/股数输入方式、自有/其他来源上限、自有缺口/合计缺口、覆盖结论及最大可融估算金额。无库存与未识别输入均保留独立结果，便于核对。

原生 App 汇总还包含询券交易台、联系人、微信群名和联系表备注；没有明确映射时交易台/姓名留空。姓名字段使用不带 @ 的纯文字，表头说明在群内 @。

## 可配置接口与文件同步

「设置」分为四页：

- **券单来源**：共享根目录、文件名模板/通配符、最新一份/合并独立券源、Sheet 名。文件名中的 {date} 替换为北京时间运行日。粘贴带日期目录时自动替换末尾日期。
- **Wind 与环境**：开关、独立 Wind Python 路径、行业字段、参数、口径名称、总超时。
- **表头与口径**：表头行（0 为扫描前 50 行）、两列取小值/单列模式、数量/金额默认单位、数字费率口径。
- **列名映射**：代码、名称、两列股数、原始市值及上限、费率、行业、券单价格、期限、来源。填写完整原始列名；留空自动识别，有歧义则报错。

默认精确匹配“申万内部券单{date}.xlsx”，不因目录中其他文件修改时间较新而误读。找不到文件时提示准确日期和文件名；不自动找上个交易日。

兼容 .xlsx/.xlsm/.xls，忽略 Excel 锁文件。独立券源可显式改用通配符和合并模式；仅去除 SHA256 完全一致文件，其他行累计，不能把同一库存不同版本当作独立券源。

启动首先读取本地有效批次清单，要求**同日、同来源、同文件筛选和选择方式**，文件存在且 SHA256 校验通过，并能按当前 Sheet/列配置解析。有效时显示“使用当日本地券单 · 未重新下载”，保留原下载时间，不检查公盘是否有新版本，不产生新批次。本地文件/清单缺失、损坏、不匹配或无法解析时才自动重新下载；只有读取失败副本而没有有效批次，也会重新尝试下载。

每次实际下载保留新批次，完整复制原 Excel，核对共享源与本地副本的 SHA256；复制过程中源文件变化或内容校验不一致则中止。全部下载和解析成功后才切换有效快照。读取失败的副本保留用于核查，并与实际使用的缓存分开显示。手动同步或自动下载失败时，才回退上述条件匹配的缓存，并显示“使用当日缓存 · 本次同步失败”。这与正常启动复用本地文件是不同状态。

跨日清空旧结果，重新执行“当日本地优先、无可用副本再下载”；每次查询也检查日期，不使用昨日券单冒充今日数据。F5/同步按钮始终强制下载，保存设置仍会同步并按新配置读取。复用库存文件不会复用旧 Wind 价格，每次查询/计算仍请求本次最新价。

导出及状态接口区分 `ready`（本次同步成功）、`local`（正常使用当日本地文件）、`cached`（本次同步失败后回退当日缓存）、`unavailable`（无有效当日库存），并保留原下载时间。

### 下载位置有很多目录，或报“只有 Sheet1”

- `data/live/日期/snapshots/批次/` 是按日期和同步批次保留的快照，每个批次内仍是完整的原始 `.xlsx` 文件，并非将 Excel 拆成子文件夹。点击「打开下载位置」直接到达本次文件所在目录，无需逐层寻找。
- 如果提示缺少“库存券单”、已有“Sheet1”，先在「文件与同步详情」查看**本次下载文件**的名字、共享来源、实际 Sheet，再用「打开本地 Excel」核对。程序不会自动改读 Sheet1。
- 文件名规则如果是 `*.xlsx*`、`*.xls*` 等通配符，在“最新一份”模式下会选目录中修改时间最新的匹配文件，可能误选其他报表。默认申万券单请点击「设置 → 券单来源 → 恢复默认文件名和 Sheet」，确认 `申万内部券单{date}.xlsx` 和 `库存券单`，再保存同步；`{date}` 保留为动态日期占位符。
- 若实际文件名已正确，仍报 Sheet 缺失，请核对打开的本地副本和公盘原文件；确认业务模板确实更名后再调整 Sheet 设置。只看到 Sheet1 时，不应直接改名绕过校验。

下载、解析、Wind 调用和导出均在后台执行，底部显示阶段，失败可重试。共享盘 I/O 返回时间受 Windows 管理，等待期间窗口可以重绘；关闭窗口会等待当前后台任务完成。Wind 子进程默认总超时 25 秒。

旧配置升级在内存完成，启动不覆盖本机文件：旧默认“*.xls* + latest”迁移到指定日期文件；原来未设置列映射时采用本版默认列名和小数费率口径；自定义列映射保留。保存设置后写入版本 2 配置。

## Wind 与环境边界

最新价使用 WSQ / RT_LAST，每次查询或计算重新请求，不缓存复用价格；行业默认 WSS / industry_sw，参数 tradeDate={date};industryType=1，按日期和字段参数缓存。

标的识别优先用当日券单；券单外代码或缺名称记录用 WSS / sec_name，券单外名称用 WSET / sectorconstituent（当日全部A股，字段 wind_code、sec_name）。名称检索范围不涵盖所有 ETF、退市证券或别名，未返回时只标记“未确认”，可以改用完整代码。名称识别与行情请求分开，识别失败仍会尝试获取已知代码的本次价格；每个子进程均受配置的 Wind 超时限制。以上新增真实 Wind 字段/权限仍须在公司终端联调，家中测试为模拟返回。

Wind 状态只表示本次请求结果，不代表持续连接。各行显示本机获取时间，明细和导出显示 Wind 返回时间；盘后/停牌 RT_LAST 可能是最近成交价，不保证为逐笔成交时间。行业请求返回错误时保留已返回价格；整个子进程超时则本次行情不可用。

公司建议 App 环境：D:\conda\envs\swhy_delta1\python.exe。现有 Python 3.13、PySide6-Essentials、openpyxl、xlrd 配置保留，本次没有新增依赖。WindPy 由用户在公司自行管理，不属于公共 pip 依赖。可以配置独立 Wind Python，该环境无需安装 PySide6。

公司用户已反馈 App 可以操作，恢复默认文件名和 Sheet 后券单读取正常；这不代表具体解释器配置、Wind 权限及 Python 3.13 兼容性已经验证。后续联调需核对实际环境与真实行情返回。诊断默认不连接 Wind：

真实券单、缓存、导出、本机配置均不提交 Git。旧网页代码保留兼容，但默认原生 App 不启动它。仓库根 README 的指数工具说明属于另一个模块。

家中修改需要先发布到 `codex/company-apps`，公司的 git pull 才能取得更新。公司保持在该分支，关闭 App，在**实际仓库根目录**检查本地改动后：

~~~powershell
git status
git pull --ff-only
~~~

若误切到了开发分支，先 `git fetch origin`，再 `git switch codex/company-apps`，成功后才执行上述 pull。任何一步报错都停止并保留现场，不用 reset/clean 强行覆盖。Git 分支控制整个仓库，切到券单开发分支可能使其他模块源码退出当前检出；切回统一分支会恢复其已跟踪文件，本机数据仍由忽略规则保留。目录叫 dashboard 不影响原生应用入口。
