# 数字 Excel 打开方式

**日常双击本文件夹里的 `start_numeric_excel.cmd`。** 公司完整位置：

```text
D:\WORKSPACE\MAIN\SwhySc\DeltaOne\project\dashboard\dashboard\start_numeric_excel.cmd
```

公司默认使用已有的 `D:\conda\envs\swhy_delta1\python.exe`，不用先打开PowerShell、激活Conda或设置变量。可给这个脚本建立桌面快捷方式，脚本本体保留在本文件夹。

打开后按向导选择“检查并补齐”或“使用现有数据”；历史任务退出后，按提示手动切回行情VPN，再验证打开。非行情接入时段使用本地缓存。

使用时保留启动终端。关闭本次Excel后自动停止；直接双击以前保存的xlsx只查看快照。

进入期现、同品种跨期或跨品种后，在首屏选择中文指标和输入 X（close／分红调整基差／基差年化）。结果默认只显示 4／4／6 个代表；用“详情”和“指标目录”导航查看全部指标、高级筛选、原始/对数口径、公式和缺失原因。原概览与对应指数仍在“概览”。操作和验收边界见 [界面使用说明](UI_SIMPLIFICATION.md)。

发布新版本时，先关闭本次Excel及启动终端，再在PowerShell更新一次：

```powershell
Set-Location -LiteralPath 'D:\WORKSPACE\MAIN\SwhySc\DeltaOne\project\dashboard'
if ((git branch --show-current) -ne 'codex/company-apps') { throw '分支不符，请保留现场' }
git pull --ff-only origin codex/company-apps
if ($LASTEXITCODE -ne 0) { throw '更新失败，请保留现场' }
```

更新后回到本文件夹，仍双击同一个 `start_numeric_excel.cmd`。根目录的旧公司专用入口已移除。
