# 展示版打开方式

公司更新：在 D:/WORKSPACE/MAIN/SwhySc/DeltaOne/project/dashboard 执行一次 `git pull --ff-only`。首次依赖检查见 [公司测试说明](APP_COMPANY_TEST.md)。

日常双击内层 dashboard 文件夹的 **start_presentation.vbs**。该入口隐藏启动控制台，只显示主窗口；也保留 start_presentation.cmd 命令入口。无需启动 Excel 或开发版。

已有历史先读，后台快检，有缺口时自动复用已保存 DDB 数据库及数据 VPN 凭据增量更新。历史任务退出后检查实时接口；若未连通，仅交易日09:30–11:30、13:00–15:00弹窗请你手动连接实时VPN。连接后点“已连接，验证并开始”，也可选“稍后连接（只读）”。程序不自动操作实时VPN或登出DDB VPN。设置、完整深核、取消、重试、导出诊断均在“数据更新 / 设置 / 诊断”。

本机原展示版：P:/project/swhy/Delta1/project/dashboard/start_presentation.cmd。
本机原开发版：P:/project/swhy/Delta1/project/dashboard/start_development.cmd。

Excel 冻结功能维护，旧入口/成品/模板/数据保留。本轮先由用户在公司测试五项主要功能，再反馈运行问题；指标与进一步美术之后再优化。
