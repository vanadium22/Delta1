# 指标补齐与三类研究页（2026-10-22）

本次按第一、第二版原稿逐子项实施非回归范围。对应指数的原概览保留；研究入口为期现、同品种跨期、跨品种，独立组合入口移除。公式实现、输入可用、端上验证和公司验收分别记录于 [逐子项覆盖表](INDICATOR_SUBITEM_COVERAGE.json)，不能由卡片标题或测试数量推断公司数据已齐备。

## 共享计算与选择

`indicator_catalog.py` 定义独立 `family_id / variant_id / input_id`、原稿来源、适用页面、公式版本、字段、频率、窗口、单位及缺失政策。`indicator_selection.py` 定义具体合约、合约对和冻结集合；`indicator_workspace.py` 仅计算当前变体的代表或当前详情页。两版 App 与 Excel 共用此服务，不在前端重复业务公式。

每个族和独立输入变体保留目录。期现默认四品种各一代表，跨期每品种一代表近远对，跨品种六组两两配对各一同期代表。选择变体后加载其卡片；未加载目录明确显示状态。全部、历史、指定合约及品种筛选按实体分页，不因某指标缺输入临时换腿。

主力在观测日之前最近完整交易日决策。全部当时合法候选的可靠最终 OI 完整时按 OI、完整成交量、到期日和代码排序；跨期按双腿瓶颈 OI/量、期限间隔排序，跨品种优先实际到期日一致。覆盖不足依次明确为成交最活跃参考、近月参考或无同期代表。当日选择冻结并保留决策证据版本。00—03仅是概览到期档位。换代表不拼接固定合约历史，B08 身份包含固定成员。

只有明确认证、带时区且不晚于决策截止的 `available_at / known_at` 证据才可认证历史可见性。其余标“修订历史参考 / 可见性未认证”，不从 bar 日期、下载时间倒填发布时间。结果保留各真实源腿时间、参考截止、有效 n、输入及公式版本、实现状态、数据状态、原因；计算期间版本变化清空整组并提示刷新。

## 补齐范围

- 原始 `F−S`、普通 bp、`10000 ln(F/S)`，未调整简单/对数年化、对数每日收敛，未调整跨期点差/标准化差、对数 carry，普通/对数跨品种同到期 G 及各自统计独立保留。
- 真实 F、分红调整 bp、分红调整简单年化及适用原稿口径各自重算均值、样本标准差、Z、半权分位、五期变化、波动、路径效率和非回归事件。原30期≤分位独立命名；概览连续档位与固定合约分位对象分开。
- 调整点数为 `F−S+D`；T 按每个历史日到实际到期日计算，T<5 年化空。单腿正 F 的 RV 用对数收益，其余有符号序列用差分；OHLC 来自真实单腿或同步序列重聚合。
- A12 保留原确认次数，补首次/末次、峰值、持续根数、确认与恢复及对应时刻。分钟缺口、换会话和午休重置，不含残差事件。
- B01—B12 补前收/开收、修复量/门槛、有效 n/权重/加权和、各腿 OI/量/CLV/RVOL/TR/基准、份额分母、固定集合成员/总量/增长、路径净变化/长度及真实容量/手数模式。参与比例 p 仅显式提供时演算，不默认1%。
- α/β/R²、回归残差、β手数、Gβ及β加权归因继续列缺口并排除。未增加第三版、新因子族、评分、有效性回测或策略仓位。

## 真实外部输入

A13 已有可调用纯函数及计算链。需按具体合约提供 `research_carry_inputs` 的融资/股息年率小数、双向成本 bp、可执行现货腿、合约到期日、有效期、真实 `known_at` 及版本。价格、有效期、发布时间、方向成本和到期匹配分别校验，无真实输入留空。理论价与方向性空间分别输出，不把演示利率装入产品。

ETF/IOPV 读取显式 `research_etf_iopv_mapping` 的 ETF、IOPV、对应指数映射及已有实时输入，校验正价格、映射和同步。结果记录真实 ETF/IOPV 两腿源时及映射版本。没有字段、映射或报价则空；本次没有采购、下载或自动配置外部输入。历史盘口不会由日线构造。

## Excel 与 App 使用

Excel 用原 `dashboard/start_numeric_excel.cmd`。本轮简化后，三个研究页独立选择中文指标族和输入 X（close／分红调整基差／基差年化），首屏显示当前4/4/6代表。完整指标目录、子输出、源腿时间、公式、n、版本及缺失原因通过首屏导航进入，替代原右侧宽表和第280行详情。历史日、具体腿、分页与p放在高级区域。无宏，选择由原COM循环读取并解析为稳定变体；只有启动器维护的同一个工作簿会计算，重开保存文件是快照。概览及对应指数、来源与状态保留。操作见 [界面使用说明](UI_SIMPLIFICATION.md)。

参与比例 p 在详情页高级区域显式填写0到1小数，仅用于B12容量演算；默认空白，合法0保留。App亦有可留空的参与比例框。启动阶段的旧计算缓存不初始化研究选择，避免覆盖较新的偏好；首次就绪恢复保存的活动页。旧关注行及已保存实体在新选择请求中继续保留。

两版 App 的真实入口仍是旧工作区 `native/editions_current.py`：展示版与继承 `native/app.py` 的开发版都接入同一个三页组件。每变体有4/4/6代表卡，可展开全部实体、筛选/分页、查看子输出、图表、公式和数据时点。原概览及对应指数代码、价格、源时保留，开发版设置和维护保留。前端仅在旧目录本地，不随公司提交发布。

选择变化先清值，每个请求有独立 `request_id`，旧结果不能填入新名称。新偏好保存为 `indicator_research_preferences.json`；原 `research_watchlist.json` 只读迁移并保留原行，不覆盖旧文件或 native/VPN 配置。完整日终序列和盘中估算分开，09:29含至15:01不含接入守卫保留，盘中结果不写回完整历史。
