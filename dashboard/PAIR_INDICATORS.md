# 合约对指标说明（contract-pair-v3）

跨期与跨品种的主指标以**这对具体合约本身**为研究对象：先构造共同价格序列、同步分钟路径或双腿量仓容量，再计算统计量。旧的各腿分别计算后比较，仍在“辅助解释”中显示。期现单腿指标、对应指数看板、原行情和配置保留。

这次定义来自用户于2026-10-22确认的合约对重构需求。它是新版本口径，不能把原稿中单腿比较的验证直接当作新指标的验证。稳定选择ID保持，计算版本明确变为 `contract-pair-v3`；原比较的辅助结果标 `nonregression-v2`。

## 如何查看

Excel 研究页先选择指标与输入，再点击详情。详情上方依次解释双腿构造、方向/单位、指标意义、使用限制；下方逐行区分主指标与辅助解释，保留公式、来源时间、历史截止、样本数、版本及缺失原因。完整目录同样包含说明。

两版 App 使用同一份定义。代表卡片和主图显示主指标，详情中主指标与辅助解释分开；点选辅助结果不会把它替换成主图指标。旧中文选择和已保存合约仍可恢复。期现/跨期/跨品种的默认代表数量为4/4/6，全部、历史、指定合约及原数据设置继续保留。

## 先定义输入X

A为左腿，B为右腿；跨期固定A为近月、B为远月。F为真实期货价，S为对应现货指数，D为该合约剩余分红点数，T为到期剩余自然日。1bp为万分之一；年化数值1表示1个百分点。

| 输入 | 同品种跨期 | 跨品种 |
|---|---|---|
| close | `F近−F远`，单位点 | `10000 ln(F_A/F_B)`，单位对数bp |
| 分红调整基差 | `10000[(F近+D近)−(F远+D远)]/S`，单位bp | `10000[(F_A−S_A+D_A)/S_A−(F_B−S_B+D_B)/S_B]`，单位bp |
| 分红调整年化 | `100[(F远+D远)/(F近+D近)−1]×365/(T远−T近)` | `36500[(F_A−S_A+D_A)/(S_A T_A)−(F_B−S_B+D_B)/(S_B T_B)]` |

跨期close/基差使用近减远，年化期限持有率使用远除近，两者的正负含义不同，界面会明确提示。年化要求两腿T均不小于5天；跨期要求远月到期晚于近月。跨品种异期组合使用各腿自己的T，同时含期限差异，不冒充同到期比较。

跨品种close不直接减两个指数的原始点位。对数价比的绝对水平依赖指数基准，应与这对合约自身历史比较；它不是回归残差，也不是按某个手数执行的实际组合盈亏。

更多口径保留：跨期未调整普通基差为`10000(F近−F远)/S`，对数价比为`10000ln(F近/F远)`；未调整简单/对数期限持有率分别为`100(F远/F近−1)×365/期限差`与`100ln(F远/F近)×365/期限差`。跨品种未调整普通/对数基差使用各自F/S后构造相对序列；年化使用各腿实际T。

## 双腿量仓如何构造

V为成交量，OI为持仓量。h表示每1手A对应多少手B：跨期h=1；跨品种采用**前一完整交易日**的`F_A×乘数_A/(F_B×乘数_B)`。当日价格变化不会反过来改变已定义的当日匹配比例。

- 匹配成交量 `V配=min(V_A,V_B/h)`，折算为A腿手数。
- 匹配持仓 `OI配=min(OI_A,OI_B/h)`。比较当期/前期时，两端使用同一个h，避免仅因换算比例变化制造增减仓。
- 共同增仓权重 `W+=min(max(ΔOI_A,0),max(ΔOI_B,0)/h)`。只有一腿增仓时，共同权重为0；总权重为0则漂移留空。

这些“匹配”量都是容量代理，并不能识别真实配对成交、共同账户仓位或实际移仓。A09仍展示**当前**名义金额和手数比作为金额解释；B02/B03/B04/B08/B09/B12使用上述前一完整交易日h。

## 每类主指标的含义

| 指标 | 主指标双腿构造 | 如何理解 |
|---|---|---|
| A03历史统计 | 对X自身取先前20期均值/样本标准差/Z/半权分位；五期变化用连续6点 | Z为自身偏离，不是两腿Z相减；30期≤分位独立保留 |
| A04/A05 | 固定近远价差及期限持有率 | 明确近−远与远/近的不同方向；自身统计不拼接换月 |
| A06 | 实际同到期合约各自标准化后形成相对基差 | 普通/对数及其自身统计独立；异期不套用同到期项 |
| A07 | `10000Δ5ln(F_A/F_B)`及现货/基差/分红情景分量 | 固定对的五期归因，未扣成本，不是调仓策略净收益 |
| A09 | 两腿真实价格乘合约乘数 | 当前金额、等名义手数、取整误差；跨期1:1金额变化另列 |
| A11/A12 | 同一会话的同步X分钟路径 | 30分钟实现波动、连续偏离事件；缺口/午休/跨会话重置 |
| A14盘口 | `Ask近−Bid远`与`Bid近−Ask远` | 两个方向分别展示，须有同刻真实价格和有效盘口量 |
| B01开盘修复 | 先形成开盘X、前收X、收盘X | repair正值表示回归，1为恰好修复；跨期/跨品种开盘用09:31同步分钟代理 |
| B02加权中枢 | 同刻X以`min(V_A,m,V_B,m/h)`加权 | 全日需240个完整同步分钟；HTTP采集区间另行标识，不冒充全日VWAP |
| B03增仓漂移 | `Σ5(ΔX×W+)/Σ5W+` | 双腿共同增仓时，合约对X向哪边移动 |
| B04换手/增仓 | `Q=V配/OI配前`；同h计算ΔOI配和`K=100ΔOI配/V配` | Q为倍，K为%，增仓为A腿折算手数 |
| B05迁移形态 | 近月减仓与远月增仓取可对应部分的较小值 | 已是联合定义，保留；不证明账户实际移仓 |
| B06份额偏移 | 远月成交份额减昨日远月持仓份额 | 正值表示流量较存量更偏向远月 |
| B07收盘位置 | 同刻分钟X形成自己的高低收，再算`(2C−H−L)/(H−L)` | 1在该对当日最高，−1在最低；不用`H_A−H_B`伪造组合最高价 |
| B08持仓扩张 | `100ln[OI配_t/OI配_t−5]`，两端固定当期h | 研究具体合约对的容量增长；原品种固定集合增长仅作辅助 |
| B09成交活跃 | `V配_t/median(此前20期V配)` | 1为自身典型水平，2为两倍；两腿同时放量仍能体现 |
| B10路径效率 | `Δ5X/Σ5|ΔX|` | −1到1，越接近两端越单向；零路径留空 |
| B11振幅压力 | 合约对分钟高低收形成绝对TR，再除此前20期TR中位 | 倍数；不除以可能为0或负值的价差水平 |
| B12成交容量 | A容量`min(V_A,V_B/h)`；B容量`h×A容量` | 真实成交的容量代理；显式参与比例p可留空，合法0保留 |

例如，两腿各自成交都变为自身常态的两倍，旧`ln(RVOL_A/RVOL_B)`可能为0；若匹配容量也翻倍，新B09为2。两腿价格都上涨、但价差完全不动，合约对漂移应为0，不能因两腿各自增仓权重不同而产生虚假漂移。

## 缺失、时点与辅助解释

日线按同一交易日对齐，分钟按同一源时刻和交易会话对齐。缺腿、缺前一完整日h、缺连续窗口、分母无效、年化临近到期均留空并说明原因。最后有效旧历史带日期展示，不标成当前值。所有参考统计排除当前观察；盘中值不写回完整历史。

B09的合约对同刻累计量基准、B11的合约对HTTP采集区间压力目前没有完整可用的独立盘中计算分支，显示原因及日终主指标；原单腿盘中比较仍以辅助项保留，不拿它冒充合约对主指标。

辅助区保留：原输入差及对应统计、各腿增仓漂移与原差、各腿CLV与原差、RVOL与原对数比、TR/压力与原对数比/最大值、固定品种集合成员及增长、原当前h容量等。辅助量单位可能与新主指标不同，例如跨品种原始点差是点，新close是对数bp；不得直接比较数值大小。

定义文字统一来自 `pair_catalog.py`，价格与量仓构造来自 `native/pair_metrics.py`，三端共用 `indicator_workspace.py`。本轮不下载行情、不移动历史、不重写既有配置、不安装依赖，不自动打开成品或弹出对话框。
