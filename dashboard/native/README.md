## 1. 使用顺序

1. 双击上级目录 `start_app.cmd`，或运行 `python -B -s -m dashboard`。初次启动的数据源为空。
2. 用侧栏「查看合成演示」检查界面。演示覆盖四个指数、四种股指品种，日频、分钟与秒级；价格、日期、到期月份均为测试样例。图表滚轮缩放、拖动和悬停；页面下方可播放历史，回放默认不写真实结果。
3. 未来新下载完成后，退出演示，在「数据与任务」添加包含 `dataset.json/current.json` 的数据集目录。指数与期货可放不同数据集；日、分、秒也可分别选择来源。
4. 「保存路径与设置」可修改新实时保存目录、新 `reference.json` 和看板结果目录。保存后生效，旧文件不迁移或删除。
5. 打开「公式工作台」，编辑 Python、输入声明、参数后试算，再发布。发布的指标自动显示于市场观察。修改同一 ID 产生新版本；取消启用后发布即可停用。

真实数据、实时热库、参考资料均只来自用户明确选择的新目录。不能从文件名判断数据真实来源，添加历史目录时会检查标准元信息和标的类型；下载来源的真实性、交易日历、单位认证还需要下载程序保证。

启动排查：`start_app_recovery.cmd` 直接打开窗口；所有正常启动会在 `dashboard/runtime/startup/` 留下日志。窗口复用只在收到旧窗口的激活确认后退出新进程；创建通道失败也继续打开前端。若结果目录正在被另一实例占用，界面仍显示指标并提示“结果未保存”，文件写锁保持有效。

## 2. 指标口径

| 指标 | 本版计算与限制 |
| --- | --- |
| 指数涨跌 | 当前价格相对该交易日已知的正式前收/上一交易日收盘；无前收就显示缺失；实时观测缺源日期时不推造日涨跌 |
| 跨期价差 | 近端 close − 远端 close；精确匹配 event_time、trade_date、session_id |
| 盘口买入/卖出价差 | 买入近端 ask − 卖出远端 bid；卖出近端 bid − 买入远端 ask。要求有效未交叉一档、接收过期≤30 秒、两腿接收偏差≤3 秒；源事件日期待核验 |
| 期现基差 | (近端期货 / 对应指数 − 1) × 10000 bp；同刻对齐，尚未扣除分红、资金成本和费用 |
| 价差 Z 值 | 当前值相对此前 30 个对齐值的均值/样本标准差；当前值不进入参照窗，分钟/秒级只用同交易日同会话数据 |
| 价差分位 | 当前值在此前 30 条价差中的经验位置，显示在 Z 值卡片；绝对 Z≥2 使用颜色标记观察，不自动下单 |
| 短窗实现波动 | sqrt(sum(30 个 log 收益²)) × 10000 bp；需要 31 个连续价格；遇缺口、午休、跨日或无效价格停止输出；非年化 |
| 期限结构 | 同一个事件时刻的具体合约价格；有新挂牌资料时过滤尚未上市/已到期合约；没有资料时明确标记代码排序未认证 |
| 区间表现 | 各价格相对各自显示区间首价的变化，用于图形比较，与正式日涨跌分开 |

数值是行情观察指标，当前没有交易执行、异常推送或收益回测。窗口不足返回 None，界面显示暖启动/输入不足；质量位和时间假设保留限制标记。停盘时保留末次数据时刻，不构造假新行情。

## 3. 日频、分钟、秒级怎样读取

`MarketDataRepository` 在 `dashboard/marketdata/repository.py`，只接受显式 root。每次计算冻结所有来源的 manifest 版本，按具体标的、频率、字段投影、时间窗口读取；只使用 `is_final=true`、`event_time<=as_of`、`available_at<=as_of` 的数据。未知可用时间默认排除，必须勾选研究展示开关才允许，并保留限制标记。

- `unit=bars`：读取最近 N 个有效 bar，修订合并后计算条数。
- `unit=trading_days`：只用于 1d，取最后 N 个有数据的交易日；没有完整新交易日历时不能认证“应有但缺失的交易日”。
- `unit=seconds`：只用于真实 1s，读取 `(as_of-N秒, as_of]`，有缺口就少行，不以最近 N 次 HTTP 请求替代时间。
- 同一标的/频率有多个来源时，公式必须指定 `dataset_id` 或移除重复来源，不静默拼接。基础卡片当前不提供跨来源择优。

UI 后台线程读取和计算，不把全部秒级历史载入前端。当前单次声明 1–8 个输入，每个输入最多 2000 行；历史回放只提供近端合约最近 2000 个 bar 的时间轴。单个冻结数据集版本可复现读取，未来任意长区间需要分段回放。

App 回放是基于当前冻结版本的修订后研究历史，控制市场事件/可用时间；不是还原下载系统当年的知识状态。严格当时已知实验应使用底层 `knowledge_at` 与冻结旧版本 API，当前 UI 尚未提供该模式。

## 4. 公式模板

程序先按输入声明读数据，再把少量字典行送入独立 Python 进程。代码不能直接打开文件或调用网络。四个内置模板：跨期分钟 Z 值、日频背景与分钟偏离、秒级短窗偏离、实时盘口跨期价差。

```json
[
  {"name":"daily","instrument_id":"$spot","frequency":"1d","fields":["close"],"count":60,"unit":"trading_days"},
  {"name":"minutes","instrument_id":"$near","frequency":"1m","fields":["close"],"count":120,"unit":"bars"}
]
```

```python
def compute(inputs, params):
    daily_mean = sma(inputs['daily'], 'close', params['daily_window'])
    minute_mean = sma(inputs['minutes'], 'close', params['minute_window'])
    latest = last(inputs['minutes'], 'close')
    return {'分钟偏离': None if minute_mean is None or latest is None else (latest / minute_mean - 1) * 10000}
```

参数例：`{"daily_window":20,"minute_window":30}`。`$near/$far/$spot` 按当前品种绑定；可以改成具体代码或增加 `dataset_id`。新本地 `IC00/01/02/03.CFE` 别名必须存在当日且当时已知的新映射。

实时输入声明：`{"name":"quote","instrument_id":"$near","kind":"quote_observation","fields":["bid_price_1","ask_price_1"],"count":1,"max_age_seconds":30}`。当前支持最新一笔观测，时间是完整接收时间，不等于源事件时间；跨腿输入偏差超过 3 秒不计算。

帮助函数有 `last/column/sma/aligned_difference/zscore/mean/stdev/sqrt/log` 等；`aligned_difference` 先按时刻/交易日/会话对齐。禁止 import、属性访问、循环、递归和任意函数调用；限制数值运算、输入 2MB、子进程 3 秒与输出规模。这是受限模板运行器，不支持任意 Python 研究脚本或第三方库导入。

可直接使用的完整示例见 `../data_contract/formula_inputs.example.json`。

## 5. 采集模块边界

`native/collection.py` 调用已有 `MarketDataClient/collect/DualIdentityStore`，不复制接口代码，不读取原项目商品主力表或旧交易日历。打开 App 不启动采集。先选择新的实时目录、保存订阅代码，再显式点击「采集一轮」或「开始采集」；关闭 App 会停止它发起的任务并保存结果。

只接受已注册国内指数和 IF/IH/IC/IM 具体年月合约；00–03 使用新参考资料，缺资料即报错。当前没有可靠主力判断，不生成 `IC.CFE` 主力映射。

现采集器的 SQLite 可桥接为观测：close、盘口、累计量、完整 received_at、稳定 observation_id、游标等；alias/concrete 去重。不把它直接转换为标准 1s/1m bar，原 Parquet 尚不足以单独恢复全部接收精度。完整字段与限制见数据规范和读取设计文档。

实时 SQLite 和结果 SQLite 要放在本机磁盘，现有存储模块会拒绝网络共享盘。目录可自选；路径保存不会移动旧数据。

## 6. 结果与本机设置

```text
dashboard/localsetting/native.json                         原生数据源/路径配置
dashboard/localsetting/native_formulas.json                当前公式列表
dashboard/localsetting/native_formula_versions/<id>/...    不可变公式版本
<自选结果目录>/dashboard_live/results.sqlite3               热库，去重/重启恢复
<自选结果目录>/formulas/<id>/<version>.json                  公式版本
<自选结果目录>/factors/<id>/<version>/YYYY/MM/<日期>.*.parquet
dashboard/localsetting/demo_results/                       与真实结果隔离的演示档案
dashboard/runtime/native_demo/                             合成演示原始样例
```

历史结果按该指标输入的交易日分区；纯实时指标按接收日分区并标记源日期未知。记录实际合约、公式版本、各频率来源版本、截止时刻、质量和输入声明。相同输入/版本不会因 UI 时钟刷新而多写一行；新 bar、修订或新观测会进入计算。首次、约 60 秒、手动「发布 Parquet」与正常关闭时归档。

改结果路径后旧结果留在原目录，新结果写入新目录；本版档案页显示最近 200 条，有重启读取，尚未做全历史检索或恢复所有遗漏时段的自动补算。
