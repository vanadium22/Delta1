# 一多一空基差研究：第一版指标

更新：2026-10-12。入口：启动 `dashboard/start_developer.cmd`，打开「专题与自定义指标」顶部的「一多一空研究」。支持日频和分钟频率、品种筛选、点击组合查看解释与历史曲线。三个标签分别为期现偏离、跨期组合、跨指数组合。默认启动使用日频。

本版下载并使用真实历史行情，建立可解释的观察指标；没有进行策略回测或下单。方向文字表示“如果偏离回归”的假设，Z=±2 是预先指定的观察阈值，未用收益优化。没有偏离也照常展示，不强行生成交易机会。

- 分钟样本：2026-10-09，每标的下载 241 条；剔除 09:30 的开盘观测后，每标的 240 条，共入库 4,800 条。
- 合约上市及最后交易日期来自 DDB 的 Wind `cfuturesdescription`，16 个合约全部取得。原请求中的 688 个无数据日期全部在合约挂牌前；导入程序逐项核对后排除，未忽略挂牌区间内缺口。
- 原始日线批次：`raw/historical/20261012_151838_9f8f1685/run.json`。原始分钟批次：`raw/historical/20261012_151756_86254b46/run.json`。
- 来源：项目公共行情接口及其独立 DDB 工作进程。日线来自 Wind 指数/股指期货日行情，分钟来自 CSMAR 指数/股指期货分时。原始 Parquet 合计 10,250,550 字节，另有字段及校验元数据。

不提供真实历史发布时间，因此 `available_at` 留空，开启明确标记的历史研究展示。`recorded_at` 为下载时间，合约资料 `known_at` 也为下载时间，不倒填为过去已经掌握的信息。日线按交易日 15:00 北京时间对齐；分钟保留源收盘标签，原始分钟区间边界尚未独立认证。日线数据不混用结算价。没有生成秒级数据。

## 指标及经济逻辑

记 F 为期货、S 为对应指数，T 为行情当天距最后交易日的自然日，m 为每点合约乘数。ACT/365；bp 为万分之一。统计窗口在具体合约内部，不跨合约拼接。

| 类别 | 指标与公式 | 如何解释一多一空 |
| --- | --- | --- |
| 期现 | 基差 `10,000×(F/S−1)` | 正数为升水、负数为贴水。相对合理价值偏高时考虑空期货多现货；偏低时相反。合理价值还需分红、融资和可实现成本，不能直接把负基差当作利润。 |
| 期现 | 对数年化 `100×log(F/S)×365/T`，及其历史 Z | 调整剩余期限的量级，距到期不足 5 天隐藏。页面基差 bp 是简单比值，年化是对数口径，名称与说明保持区分。 |
| 期现 | 假设每日收敛 `−10,000×log(F/S)/T` | 仅作贴水/升水按剩余自然日线性归零的量级，假定指数不动且没有分红跳变；不是逐日实际收益或持仓建议。 |
| 期现/跨期 | Z、历史分位、5根变化 | 当前值对“此前20根”均值及样本标准差；分位对并列值取半权。当前值不进入基准。基差自然收敛可能改变原始 Z，年化 Z 作为旁证。 |
| 跨期 | 点差 `F近−F远`；标准化价差 `10,000×(F近−F远)/S` | 同品种固定一手多近空远，点差扩大受益；Z偏高时回归假设为空近多远，偏低时反向。标准化价差会受 S 变化影响，不等同固定手数损益。 |
| 跨期 | 区间隐含持有率 `100×log(F远/F近)×365/(T远−T近)`，及其 Z | 表示两到期日之间分红、融资和供需的综合定价。期限差越长，绝对点差不宜直接横比。负隐含持有率不是无风险获利率。 |
| 跨指数 | 同月对数基差差 `10,000×[log(FA/SA)−log(FB/SB)]` | A相对自身现货比B更贵或更便宜；相同月份避免期限错配。Z只提出基差差回归假设，不证明指数风格收益能够相互抵消。 |
| 跨指数 | 指数 β 与 R² | 对此前60个同期对数收益拟合 `rSA=α+βrSB+ε`，当前收益不参与。衡量两指数的共同波动与线性拟合程度，不是协整、稳定性或盈利证明。 |
| 跨指数 | 等名义 B/A 手数 `FA×mA/(FB×mB)`；β对冲手数 `β×FA×mA/(FB×mB)` | IF/IH乘数300，IC/IM乘数200。不同指数一手金额不同，不能默认一手对一手。理论小数手数需另行考虑整数取整和残余敞口；β≤0或不可估计时不输出一多一空β手数。 |
| 跨指数 | 最近5根的期货、指数、基差变化分解 | 等名义对数口径精确满足 `期货收益差=指数收益差+基差差变化`，将指数强弱与衍生品定价分开。另提供固定当前β的加权分解，仅作归因诊断，不声称为逐期调仓实际收益。 |

跨期覆盖每品种四个合约的六种两两组合，共24组；跨指数覆盖六种指数配对的四个共同月份，共24组；期现共16项。日频64项，分钟64项。

“5根”随所选频率变化：日频为5个交易日区间，分钟为同会话5分钟区间。分钟的20根统计及60收益回归必须同日、同会话、相邻分钟连续；不跨午休/隔夜估计。零方差、样本不足、非正价格、最新错时、重复键均不会生成有效当前统计。新挂牌2611只有9条日线，其Z与分位保持空值；跨指数β仍可从独立指数历史估计。

## 这批样本说明了什么

截至2026-10-09 15:00，IF2612 / IC2612 的对数基差差为 +25.72 bp，Z约 −1.58；这表示水平仍为正，但低于自身近期均值，不能把“正数”与“偏高”混为一谈。

同一组合最近5根日线的等名义对数收益差约为 +165.74 bp，可分成指数收益差 +223.28 bp 和基差差变化 −57.54 bp。两部分方向相反，直接观察期货强弱会掩盖基差变化。此前60根指数收益估计β约0.580，对应每1手IF理论对冲约0.519手IC；这是敞口换算，不能将“指数β对冲”称为纯基差套利。

截至同日，IC/IM的指数收益R²约0.952，IH/IM约0.352。前者在这段样本里的线性共同波动更强；后者需要更重视风格敞口。这个比较仅描述已有样本，不推断哪一组未来更赚钱。

分红和融资尚未接入：理论价偏离卡片继续留空。定价关系参考 [CME Calculating Fair Value](https://www.cmegroup.com/trading/equity-index/fairvalue.html)，它说明指数点位、融资、股息与期限共同决定理论价格。本版的20/60窗口、Z阈值和组合诊断属于本次实现选择。合约乘数参考中金所 [沪深300合约细则](https://www.cffex.com.cn/u/cms/www/202003/27165436e0mo.pdf)、[上证50合约细则](https://www.cffex.com.cn/u/cms/www/202003/27165822h30l.pdf)、[中证500合约规格](https://www.cffex.com.cn/u/cms/www/oldsys/W020150327602765122017.pdf)及[中证1000合约规格](https://www.cffex.com.cn/u/cms/www/202207/18190308vxpv.pdf)；历史PDF中的交易时段/保证金等参数没有用于本版交易设定。实际到期日使用此次DDB下载结果。

## 更新命令与检查

以下命令从 `P:\project\swhy\Delta1\project` 运行，Python使用现有 `swhy_delta1` 环境。下载脚本默认只预览；显式 `--download` 才写行情，每次保留独立批次，不启动持续采集。

```powershell
python -B -X utf8 -s -m dashboard.download_basis_data --start 2026-06-01 --end 2026-10-09 --months 2610 2611 2612 2703 --frequency 1d --download
python -B -X utf8 -s -m dashboard.marketdata.ddb_import --run <明确选中的run.json> --output dashboard/data/ddb_basis/normalized --reference dashboard/data/ddb_basis/reference_20261012.json --register
python -B -X utf8 -s -m dashboard.verify_basis_research --captures
python -B -X utf8 -s -m unittest discover -s tests -p test_basis_research.py -v
```

下载新月份时还需通过 `ddb_reference_worker.py` 获取对应参考资料（使用公共DDB `.venv` 解释器）；它复用公共 `Client` 的只读连接和VPN释放流程，不复制连接密码。参考资料使用新文件名留档。导入要求完整批次，或仅缺少已核验挂牌区间外日期的 partial 批次；部分失败、未知缺口和哈希不符会拒绝入库。相同内容重导幂等，价格修订冲突要求人工核验后明确新修订，不能静默覆盖。

已完成8项新增计算/导入边界测试、73项原生看板回归测试；阶段发布范围修订后相关5项测试再次通过。真实数据日/分钟组合的收益分解最大绝对误差小于 `6×10⁻¹² bp`。规范数据合计5,872条，原始及转换后数据均保留来源审计。离线验收结果和三个标签截图位于 `dashboard/data/ddb_basis/verification/`，默认发布快照位于 `dashboard/runtime/published/`。

研究优先顺序：先比较同一指数的不同期限，分离期限持有率与短期价差偏离；再比较同月份跨指数基差，同时核对指数收益分解、β与R²。期现方向待ETF/篮子、分红和资金条件具备后再讨论实现。所有结果均为行情研究，不以是否进行后续回测为前提。
