## 分红与价格口径

Excel 只用 openpyxl `data_only=True` 读取已保存的缓存值，不刷新 Wind、不改源表。
按 Sheet1!B1 选择最新快照，忽略临时文件；相同有效输入合并，同日冲突则不可用。
本机当前快照为 2026-09-18。B/G 列提供档位及点数，C/E 列冲突不参与合约识别。
Sheet2 的未来零值不作为未来分红为零的证据。

当前固定情景锚定 **2026-10-16**，独立 DDB 合约参考将每品种00—03明确映射到
2610、2611、2612、2703。这个映射及其点数有独立哈希版本，并在界面常驻提示和设置表中展示。
源快照日期与情景映射锚定日分别标注。新上市月份不自动继承旧档位点数。
「建立新的固定分红情景」会先展示新的具体合约映射，保存后按新版本完整重算；不拼接旧版本指标。
旧历史合约没有明确映射时，分红相关指标为空，真实价格、量仓等其他指标仍可用。

统一采用：

```text
F_adj = F + D
调整基差点数 = F − S + D
调整基差bp = 10000 × (F − S + D) / S
简单年化% = 100 × (F − S + D) / S × 365/T
跨期调整点差 = (F近 + D近) − (F远 + D远)
```

T 来自实际到期日与自然日，T<5 不输出当前年化，T≤0 不输出收敛量级。
历史表可显示最后有效历史值及其原日期，盘中列不会用旧年化值填充。
固定情景历史按同一具体合约、同一 D 版本重算，不能称为真实逐日剩余分红。
本次没有混用对数年化。对数仅用于真实正价格的收益分解和明确定义的量仓增长/比值。

未来逐日输入在设置页导入以下 JSON；必须具体合约、精确日期，无缺失填零或日期前填：

```json
{"schema":"contract_daily_dividends_v1","rows":[
  {"date":"2026-10-16","instrument_id":"IF2612.CFE","points":16.5}
]}
```

这只是格式示例，16.5不是新增实测数据。实际文件内容形成独立版本。

## 指标和时间边界

| 编号 | 本次保留 |
| --- | --- |
| A01—A07 | 分红调整点差/bp、简单年化、假设收敛、历史Z/分位/五期变化、跨期价差/持有率、同月跨指数基差差、实际期货收益非回归分解 |
| A09 | 真实价格等名义手数、每手金额和整数匹配金额差 |
| A11—A12 | 连续30分钟波动、调整基差/跨期连续偏离确认 |
| A13—A14 | 理论价成本带、ETF/IOPV缺输入时明确不可用；真实一档双向跨期观测报价 |
| B01—B04 | 开盘偏离与修复、量加权中枢、增仓加权漂移、换手与净OI变化 |
| B05—B08 | 跨期迁移代理、成交与持仓份额差、收盘位置差、固定同组月份持仓扩张差 |
| B09—B12 | 相对成交活跃度、路径效率、相对振幅压力、按等名义或同品种1:1手数折算的双腿成交容量 |

A08、A10以及所有 β、α、R²、残差、β手数/归因/事件和 C01—C06 不在默认研究视图。
日频 Z/分位使用此前20个值，样本标准差 ddof=1，分位为相等值半权；五期差需连续6个值。
分钟波动用30个连续变化；偏离确认用此前30分钟Z，同方向绝对Z≥2连续3根确认一次，跨会话/缺口重置。
均值、标准差、分位不属于被排除的回归拟合。

适用指标可切换真实期货价格、调整基差bp、调整年化百分点。跨指数不直接相减两个不同指数的真实点价。
有符号基差用差分与对应单位的波动，不套价格百分比/对数收益；振幅按自身历史振幅归一，不除以前一期基差。
基差开高低来自同步分钟收盘观测聚合，并明确标为该采样口径；不由两腿日线高低价相减构造。
基差开盘修复使用首个09:31同步收盘观测，不能称作精确开盘成交。

实际期货收益差=指数收益差+未调整对数基差差变化；分红情景变换单列。
F+D 的变动不当作真实期货收益。名义金额、手数和盘口全部用真实价格。
双腿容量显示100%已发生成交量的折算基数；参与比例 p 应乘该基数，不是可成交承诺。

完整历史日线、完整历史分钟、盘中截至当前、采集以来分开标注。
完整历史量才进入日频 RVOL；盘中累计量只用于单独的累计成交容量。
采集区间中枢只对连续同会话、同步HTTP观测的有效增量量加权，首次、断线、回退、跨会话重建基准。
它不是完整交易所分钟线，也不是开盘以来VWAP。

## HTTP实测与限制

2026-10-16 14:37:42—14:37:46连续三轮，以及14:58:46原生界面的一轮，均返回20个标的。
20个标的最新价、OHLC、昨收、累计量均保存；16个期货OI原值仍为0，保留原值和不可用原因。
历史其他来源的合法零OI不删除；到期归零不产生普通撤仓/迁移信号。
期货二至五档异常哨兵过滤为缺失，一档须有效非交叉且有量才生成双向报价。
指数一档没有有效价格时显示缺失。

当前仍缺：有效实时OI、完整源行情日期、已确认单位的昨结、融资/成本和ETF/IOPV输入、真实逐日剩余分红。
例如 IF2612 昨结原值为 4077400000，未经认证不会用于涨跌计算；涨跌使用接口昨收。
盘中 closingPrice=0 / final=false 不替换 latestPrice，完成状态单独保存。
源时分秒、完整接收时间和日期推定状态均保存；30秒新鲜度同时检查接收与推定源时间，跨腿均检查3秒偏差。
会话外、时钟倒置和陈旧缓存不能作为有效盘中指标。只有时分秒不能证明真实源日期，界面始终保留未认证提示。
