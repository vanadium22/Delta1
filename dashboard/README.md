## 页面与数据

市场概览包括指数、ETF、股指期货；其他研究页暂时停用，源码与32项定义保留。每品种四张期指卡（共16张）显示实际合约，各自按当前 00/01/02/03 连续月份档位的年化基差历史计算 20/60 交易日分位。当前和历史均用分红调整简单年化，缺D仅继承前一到期合约并标来源。当前日排除，已知 T<5 另列规则排除，真实缺价或映射不跳过。研究 A02 的具体合约口径独立保留。

最新价、行情源时间、接收时间、计算及页面应用时间分别保留。连续交易仍用 30 秒时效和 3 秒配对；午休、盘前盘后与已完成收盘参考分开。历史齐备不等于当前报价可用；缺 IOPV、净申赎或 PCF 来源时明确留空。

主HTTP每三秒、成分默认300只/15秒、仍约5分钟一轮独立，缺项下轮优先、低回包下一轮降100。概览自动Wind只用于低频成分、权重、行业、同指数ETF规模及日频净值/同日收盘，复用原 WindPy / 用户 site；个股昨收用HTTP yesterdayClosePrice，已有有效部分即可算行业篮子/贡献，保留覆盖和权重日；完整资料周度复核，缺项每日有界修复。行情分析另按用户所选标的/窗口显式请求Wind分钟/日线，不创建研究服务。App仅补概览所需日线，默认不补全部成分日线/锚点，不下载研究分钟历史；成分每批持久保存raw/SQLite及分类显示缓存，原Parquet保留。先复用本地有效标准历史/收盘缓存，再经明确源日或连续盘中双证据核验的HTTP昨收，DDB仅补剩余历史价格或当前16合约最近完成日OI实际缺口才按原政策准备数据 VPN；实时 VPN 由用户手动连接。
