# 回测所需数据与核验口径

运行前通过 `audit` 查看所选活动数据集的具体合约、频率、覆盖区间和参数缺项。报告写入本机忽略目录，不随源码提交。覆盖声明不能替代实际非零目标及持仓单元格的检查。

## 必需输入

1. 每个交易标的的原始 close，以及对应指数 close。现货按品种映射为 `IF_spot` / `IH_spot` / `IC_spot` / `IM_spot`。
2. 合约乘数；支持独立时变表，内置股指品种标准乘数。
3. 保证金率；提供逐时点历史表，或明确选择固定比例假设。合约规则最低标准不能代替实际账户的历史保证金率。
4. 可选挂牌/到期参考，限制具体合约的合法区间；不凭历史最后一条价格猜测到期结算。
5. 分红调整价或剩余分红点数，供上游信号和基差研究使用。默认账户盈亏、手续费、资金占用使用原始 close。

本地现有活动行情是否齐全，以本机 `audit` 报告及实际回测校验为准。行情 schema 与合约参考若不含保证金率，应由独立表或显式假设补充，不填零。基础 close 价差核算不要求把预计分红当现金收益。

## 日线与分钟组合

运行按需读取两个频率。日线用于每日 close 估值和缺少分钟时的真实收盘成交回退；分钟用于寻找信号后的首个共同有效成交价，以及自动模式的逐报价风控。日频模式只保留必要的首条分钟报价和每日 close，自动模式保留有持仓或信号的必要日内数据。全为零的合约不要求价格或保证金率，只保留日结账户及指令位置。

有单独 `daily_close_path` 时优先用其日末值；单个标的缺日线、但同一日末时间有实际分钟 close 时可以补入该真实观察。没有独立日线的输入矩阵使用当天最后观测并保留其时间，不把较早分钟价换标签假装收盘价。缺少有效日末持仓价格会报错。

所有成交仍严格晚于有效信号，日频信号不在同一天较晚标注的 close 偷跑。无分钟报价时 `price_source="daily_fallback"`、`execution_precision="1d"`，真实成交时刻为该日线 close；存在分钟缺口时在元数据保留缺口数量。原始分片按活动 manifest 及 SHA 校验，不扫描孤立文件。

## 分红和历史信息边界

`dividend_policy="none"` 默认不套快照；`"asof_snapshot"` 明确从快照日期之后应用具体合约的缓存点数，之前及未覆盖合约保留缺失；`"fixed_scenario"` 是显式固定分红情景，可用于更早区间并在元数据注明该限制。按 C 列具体合约和 G 列点数映射，不用滚动别名或源表 E 列猜测到期。

固定快照情景的调整价缓存不能替代独立的逐日历史分红输入。历史发布时间未知的数据须显式允许修订历史研究；延迟一条行情成交本身不能证明数据在当时可知。

内置乘数参考中金所官方细则：[IF](https://www.cffex.com.cn/u/cms/www/202003/27165505w3j5.pdf)、[IH](https://www.cffex.com.cn/u/cms/www/202003/271658063l8q.pdf)、[IC](https://www.cffex.com.cn/u/cms/www/202003/27165856gzzt.pdf)、[IM](https://www.cffex.com.cn/u/cms/www/202207/182020307zry.pdf)。手续费默认每边名义本金万三来自回测参数要求，不声称为实际历史费率。
