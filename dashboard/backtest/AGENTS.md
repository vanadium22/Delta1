# 回测模块约定

遵循仓库根及 dashboard 的 AGENTS，开发和发布使用 `codex/company-apps`，只提交明确文件清单。

- 当前标准见 DATA_FORMAT.md / WORKFLOW.md：唯一 data 配置入口、因子与 CTA 独立保存/重读、每函数独立参数声明；桌面四页设置分别恢复，不将 CTA 阈值或变换写入原始因子。新模板明确固定保证金 100%，旧显式情景保持原值。
- 2026-11-03 结构研究见 TERM_STRUCTURE.md：期现按 T 年化，01−03 按 T03−T01 年化；报告同时给实际自然日 CAGR。条件分位回归仅用前序日期，因子单独保存 p/q/β/训练范围，CTA 不拟合。各实际合约 pair 在同品种共享资金，preserve_pair_lots 保持其他 pair 事件下旧手数；指数虚拟腿对账实际净额，不虚构毛额手续费或保证金。
- 不再隐含发现 native。宽表/注册集/旧配置适配器选择冲突报错；注册集按活动或指定 manifest 冻结。DDB 获取按用户最新要求继续暂停，不检查路由或连接 VPN。
- neutral_units 模式按品种要求合约等价手数权重和为零，指数数量由整数期货手数及乘数生成；跨期每品种一组反向等手数，任一到期双平。实际资金占用仍逐腿按价格×乘数×保证金率。旧 capital/主腿预算模式保持兼容。

- 本模块为独立本地回测及桌面入口，普通回测和桌面不启动行情采集、Wind、DDB、公盘或 VPN，不下单。显式 `acquire_daily` 只在已有 DDB 路由可用时只读抓取日线/挂牌到期参考，写新 data 快照；命令本身不连接 VPN，不自动调度。
- 输入为完整的目标资金占用比例大表。默认日频取当日最后目标，在下一交易日首个共同有效价格执行；自动保留输入日内时刻。分钟不可用时在真实日线 close 时点回退，不伪造开盘价或提前成交。
- 权益和持仓统一日结。日频仅在收盘检查爆仓；自动模式检查每个实际可观测报价，允许批量向量化扫描。无事件时点不逐条核算或输出。
- 单标的/同品种的独立账户及注册行情分日预处理支持有界多进程；共用资金组合统一结算，避免拆散账户改变手数。保留数据位置、指令加载器和实际开平仓输出接口。
- 爆仓默认比较账户总权益：`equity < required_margin * 0.0001`。`available_equity` 输出字段是保证金后余额，不能混为默认判断项。
- 不填充交易价格，不猜测保证金率，不用分红调整价代替真实成交价；固定分红假设须明确标记。
- 剩余自然日从明确到期参考或逐日 T 表取得；默认 d0=0，T<=d0 当天 close 强平对应合约，禁止新增临期持仓。未知 T 不静默跳过。00—03 输入先按信号日期展开，实际成交只用具体合约。
- 因子/CTA 在连续档位计算，输出映射回实际合约；历史分位和 Z 统计排除当前日期。年化基差及分红版本规则复用既有项目，不恢复暂停的研究服务。
- 关联对冲从期货整数手数生成反向指数单位，IF/IH 每手 300，IC/IM 每手 200；主腿目标预算两腿总资金占用与费用。`contract_pair` 为每个实际期货与其指数腿建立独立资金账户；到期同步关闭关联腿，未关联现货保留。持有到期研究开启 `rebalance_on_change_only`，不能因其他账户指令或每日重估隐含调仓。
- 2026-11-03用户新授权：可只读Z来源补齐本地data，绝不修改Z文件。只有显式 readonly_import 和授权参数可读取；输出必须是本仓库data中的新快照，带逐文件SHA、逐格来源、映射/T/日历/重叠审计。运行时仍禁止直接Z路径；使用新快照须 data.allow_readonly_z_import=true 和 source_manifest_path，读入核验输出SHA。旧未经本轮审计的 backfilled_* / excluded_mixed_source_run 继续拒绝，不自动放行旧结果。DDB获取和VPN仍暂停。
- 用户确认期现为4品种×4固定入场档位共16独立组，组间不共享资金/指数净额；每组锁定开仓实际合约至到期后，再从原档位寻找。跨期4品种各一组01−03。阈值仍abs(2p−1)>0.9/0.8。当前入口见 FIXED_SLOT_STUDY.md；旧共享资金模式保留兼容但不能替代本轮结果。
- 调参兼容目标为当前Delta1，复用workflow.factor_stage/cta_stage/backtest_stage；workflow tune只编排原阶段，不能另写执行/账户逻辑。参见PARAMETER_TUNING.md。只改CTA或费用/资金应复用原因子，窗口/模型变化需重算；桌面禁止误用旧参数因子，并保留tuning配置。图例区分期现蓝历史/紫回归与跨期蓝0.9/橙0.8。
- 自动增量更新仍留后续；本次一次性历史补取入口独立于 App。真实 VPN 操作曾被自动审批拒绝，不能绕过；等待用户明确连接授权或手动接通数据路由后再继续。公司电脑必要测试已授权，现场结果单独记录。
- 真实指令、行情、分红、配置和运行结果只在本机。验证输出在忽略的 `local_artifacts/validation/<日期>/`，不提交真实数据或报告。
- 桌面设置、校验、错误和进度内联显示；开发验证离屏，不激活实际用户窗口。后台读任务可取消，写出需安全结束。
