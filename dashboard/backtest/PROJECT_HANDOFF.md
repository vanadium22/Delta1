# 回测项目交接

2026-11-02，统一分支 `codex/company-apps`。

已接入独立的大表回测模块，支持内存/文件/自定义指令读取、注册行情或自有 close 表、数据位置和实际开平仓落地接口。支持单标的、同品种、全市场账户；下一时间戳原始 close 默认成交，整手、先平后开、手续费万三、资金上限 0.99。

爆仓默认采用账户总权益：`equity < required_margin * 0.0001`。示例配置已同步。输入保证金率和逐日分红不凭空补齐；真实源覆盖以本机 audit 为准。

后端 35 项隔离回归通过，涵盖默认总权益、正权益接近阈值、参数变化、价差核算及导出。公司真实数据与现场使用尚待验收；本机验证报告不提交。

当前入口：`python -m dashboard.backtest audit|run`，或 `python dashboard/backtest/run.py ...`。下一步交付与现有 dashboard 风格一致的独立本地桌面窗口，接入路径/参数、后台运行、净值/保证金与实际持仓/成交表。
