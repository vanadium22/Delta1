# 回测项目交接

2026-11-02，统一分支 `codex/company-apps`。

已接入独立的大表回测模块和蓝白 PySide6 桌面。支持内存/文件/自定义指令读取、注册行情或自有分钟与日线 close 表、数据位置和实际开平仓落地接口。支持单标的、同品种、全市场账户；下一有效时间戳原始 close 默认成交，整手、先平后开、手续费万三、资金上限 0.99。

爆仓默认采用账户总权益：`equity < required_margin * 0.0001`。示例配置已同步。输入保证金率和逐日分红不凭空补齐；真实源覆盖以本机 audit 为准。

当前精度默认 `precision="1d"`：每个交易日取最后目标，下一交易日首个共同有效报价执行，仅收盘检查爆仓。`"auto"` 保留输入精度，对每个实际可观测报价检查爆仓。两者的权益和持仓都只输出每日 close 一条。当天最后信号顺延；缺少分钟只在真实日线 close 时刻回退，成交表记录 `price_source` 和 `execution_precision`。缺少目标合约整个交易日时继续找后续首个有效报价；不把指数的可用日历当该合约已有价格。

日频按需保留首个成交分钟和每日收盘；引擎使用信号、成交、收盘事件，自动风控在恒定持仓区间向量化分块扫描报价。注册行情分日读取、独立账户核算支持有界多进程；`workers=0` 小任务串行、大任务自动最多 4 个，`1` 强制串行。全市场共用资金保持统一结算。Windows 外部 API 需有 `__main__` 保护，默认启动器已处理；取消等待自有进程安全退出，保存完整写出。

桌面左侧配置目标、数据、保证金、资金、精度和进程数，右侧为日结曲线、账户选择、费用/收益/回撤及可搜索排序的成交/持仓/账户/信号/目标明细。路径选择、配置、错误和进度均内联；支持安全取消、关闭等待、历史结果重开和移动后读取。默认总权益爆仓条件、本轮精度和耗时明确显示。

62 项回归通过，ResourceWarning 按错误处理，Ruff 通过。覆盖原资金核算、三种分组和导出，以及日末信号次日首价、真实日线回退、日结费用/盈亏、盘中暴跌与收盘恢复的精度差异、保证金时变、缺价、串行/多进程一致性和取消退出。真实分钟线桌面日频/自动均已运行，1920×1080 / 3840×2160 离屏截图已核验。自动模式 19 条成交及每日权益与原实现对账一致；日频使用日末目标产生 5 条成交、2 天日结。真实验证使用明确固定保证金假设，历史保证金率和逐日分红仍需实际输入。

本机隔离合成基准：252 天、60,480 分钟、16 标的、51 条信号，原逐分钟核算 2.070 秒，事件核算 0.077 秒，303 次估值、252 条日结，成交和日末权益一致；24 天密集信号的 4 个独立品种账户，串行 2.947 秒，含启动的 4 进程 1.820 秒，结果一致。仅代表本机该组输入，复现方法见 [README](README.md)。依赖复用既有环境，公司现场仍待验收；本机报告、截图及真实行情不提交。
