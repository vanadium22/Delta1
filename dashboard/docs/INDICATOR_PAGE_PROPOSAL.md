## 公式

同一有效定价日/时点指数S、实际合约价F_i、当时可知非负累计分红D_i、剩余自然日T_i：

```text
B_i = F_i − S
B_i^D = F_i − S + D_i
A_i = 100 × B_i^D / S × 365 / T_i
C_(j−i) = (F_j − F_i) + (D_j − D_i)
A_(j−i) = 100 × C_(j−i) / S × 365 / (T_j − T_i)
(j,i) = (03,02) 或 (02,01)
```

“绝对基差”保留正负值，不做abs。跨期分母是同日指数S，远减近、分红远减近，不将两个单合约年化相减。独立数例S=4100、F03=3960/F02=4000、D03=100/D02=40、T03=220/T02=120，去分红点差20，年化1.7804878%。

## 窗口与统计

t_w=10–365自然日含末日，默认90；例如截至11-10的90日从08-13开始。t_z=2–120交易日，默认min(20,floor(t_w/2))，90→20/30→15/10→5。关闭“自动t_z”后手动窗口不随t_w变化。四项统计共用定价日之前准确t_z交易日，不混当日多笔实时；不按t_w计算均值。

```text
μ = 历史样本均值；m = 历史样本中位数
σ = sqrt(Σ(x_k−μ)^2/(n−1))
Z = (x−μ)/σ
分位点 = 100 × (小于x的样本数 + 0.5×等于x的样本数) / n
```

σ=0或有效样本不足2时Z留空；参考历史完整而当前价缺失时保留μ/m，当前Z/分位点留空。μ/m是最新t_z统计值的水平虚线，横跨整个t_w，可隐藏。已知T<5断口/规则排除；未知缺价/映射/冲突不跳过、不向更老日期凑样本，四项统计明确缺项。历史缺D暂0只派生并列日期/来源，真实版本冲突阻断；当前D不补0。
