## 计算口径

设同一有效定价日/时点的指数价为S，合约i期货价F_i，按该日实际合约可知版本的分红点D_i，剩余自然日T_i。

```text
点基差 B_i = F_i − S
去分红点基差 B_i^D = F_i − S + D_i
去分红年化基差 A_i = 100 × B_i^D / S × 365 / T_i

跨期去分红点差 C_(j−i) = (F_j − F_i) + (D_j − D_i)
跨期年化 A_(j−i) = 100 × C_(j−i) / S × 365 / (T_j − T_i)
(j,i) = (03,02) 或 (02,01)
```

“绝对基差”沿用F−S点数口径，保留正负值，不做abs。D为合约非负累计分红点数，跨期用远减近的D差，不将两腿D相加。不能用两个单合约年化A_j−A_i代替跨期年化。

独立数例：S=4100，F_03=3960、F_02=4000，D_03=100、D_02=40，T_03=220、T_02=120。去分红点差20点，年化 `100×20/4100×365/100 = 1.7804878%`。

源码依据：`marketdata/overview_basis.py` 的F−S+D及365/T简单年化；`native/futures_overview.py` 的近远月点差不是此次两个年化通道。`backtest/strategy/annual_calendar.py` 默认01减03、分母近月期货，也可选spot；本次方向、通道、分母独立定义。只读参考旧代码，不修改回测或其发布区块。

## 统计与窗口建议

当前比较点为x，参考样本为当前定价日之前t_z个已核验交易日；当日多笔实时报价只产生一个比较点，不混入历史分布。

```text
均值 μ = 历史样本均值
中位数 m = 历史样本中位数
样本标准差 σ = sqrt(Σ(x_k−μ)^2/(n−1))
Z = (x−μ)/σ
分位点 = 100 × (严格小于x的样本数 + 0.5×等值样本数) / n
```

排当前定价日、等值半权沿用现有口径。ddof=1为本方案建议，未声称旧源码已有相同Z口径。σ=0或有效样本不足2时Z留空；历史均值/中位数可用而最新比较价缺失时，可保留参考线，当前Z/分位点留空。

t_w按自然日含末日截取，例如截至11-10的90日从08-13开始。t_z单独取前置交易日；自动默认90→20、30→15、10→5。手动t_z后调整t_w不覆盖它，重新启用自动默认才联动。示意输入范围仅供演示，正式上限结合历史覆盖和有界预算制定。

均值/中位数为最新t_z的两条水平线，横跨t_w，不是历史逐点滚动曲线，也不是t_w均值。默认显示，可隐藏。已知临期T<5明确剔除并显示有效样本/剔除数；窗口内未知缺价/映射/冲突不跳过，不从更老交易日补足。历史缺D暂0仅沿用派生政策，保留数量/日期/来源；当前D不补0，不回写原始分红。
