Delta1 公司看板 · 同事使用说明

一、解压和启动

1. 将整个压缩包发给同事，用 Windows 10/11 64 位电脑解压到本地短路径，例如 D:\Delta1。不要直接在压缩软件内运行。
2. 打开解压出的 Delta1 文件夹，双击“启动看板.vbs”。内置 Python 与常用依赖，通常无需事先安装 Python。
3. 每位同事使用自己解压的文件夹。请发送原压缩包，不要再次打包已经填写个人账号的运行文件夹。

二、首次配置数据

随包历史行情当前最新到 2026-10-16，分红工作簿快照日期为 2026-09-18；它们是已有历史，不是实时行情。较新数据需在公司网络中使用本人账号补齐。部分 Wind 行业或 ETF 资料需要本机 Wind 终端及授权。

看板内打开“数据更新 / 设置”，填写本人 DDB 账号和数据 VPN 账号并保存。VPN 网关及 HTTPS 证书 SHA256 指纹应向公司管理员核对。密码保存在当前 Windows 用户的本地加密文件中，不包含在此初始包中。DDB 可达时复用已有数据隧道；实时 VPN 按原方式手动操作。

点击补齐或更新前，请确认公司网络及相应账户已就绪。公盘默认使用 \\192.168.91.230\FTPServer\jrcx\for_jrcx\OTC-Quant\pybct\TZQ\日终基差结果\2026，直接访问仍需在公司环境核验。无需映射 Y 盘。

三、使用指标分析

每张图右上角分别设置“坐标轴窗口”（显示的自然日）和“指标计算窗口”（定价日前的交易日）。取消该图的“自动”即可手动修改指标计算窗口。输入完成后按回车或点击别处生效，只更新修改的图；其他图保持各自正常的30秒重画。各图的选择自动保存在本机，下次打开会恢复；补齐所选窗口会覆盖四张图需要的最长历史。

四个品种的年化期限结构纵轴默认显示 -10% 至 0%。有数据超出时向外扩展，日内不自动缩回，次日重新按默认范围判断。

四、Python 环境

通常直接使用内置 Python。若要选择其他 64 位 Python 3.10 或更高版本，双击“Python环境设置.vbs”，浏览选择 python.exe，点“检查环境”，缺包或版本不符时点“一键补齐依赖”，检查成功后保存选择。运行中的看板应正常关闭后重启。

随包离线依赖适用于内置的 64 位 Python 3.13。选择其他 Python 版本时，若离线包不兼容，一键补齐会尝试所选 Python 配置的 pip 源，需要网络和相应访问权限。Wind 终端、Wind 授权及公司 VPN 客户端不由 Python 补齐安装。

五、如无法启动

先在“Python环境设置”中检查所选解释器，按提示补齐。确保解压目录可写；不要在压缩包内部或只读目录运行。启动记录位于 dashboard\runtime\app_startup。涉及公司网络或账号的连接问题由公司网络与数据管理员协助核对。
