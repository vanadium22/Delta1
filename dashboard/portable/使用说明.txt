Delta1 · Dashboard 同事版

快速开始

1. 把整个压缩包解压到 Windows 10/11 64 位电脑的本地目录，例如 D:\Delta1。
2. 双击「启动看板.vbs」。默认使用包内 Python，首次启动直接显示随包历史收盘。
3. 需要补齐数据时，双击「首次配置.vbs」，或在打开的看板进入「数据更新 / 设置 → 配置 DDB 与数据 VPN 账号」。
   - 在「DDB 数据库」填自己的 DDB 账号和密码，点「保存本机数据库凭据」。
   - 在「数据 VPN」填自己的账号和密码，点「保存本机 VPN 凭据」。已有可用的数据 VPN 连接时可跳过。
   - DDB 地址、VPN 网关和证书使用配置页预填值。公司如有变更，可在设置中修改。
4. 回到「数据更新 / 设置」点「一键补齐收盘」。要看实时行情，按公司方式连行情 VPN，再点「更新报价」。
5. 可用「创建桌面快捷方式.vbs」建立桌面入口。

公盘和本地历史

双击「下载公盘分红 Excel.vbs」，或点看板内同名按钮。公司网络可访问公盘后，程序会按工作簿实际业务日补收上一自然年起的有效 Excel，自动去重并加入历史分红。完成和缺项在「数据更新 / 设置」可见。现场有自定义共享目录时，在高级设置里填写公盘目录并保存路径。

随包有四指数和股指期货的已核验本地日线、分钟行情、实际合约参考及历史分红 Excel。具体起止日期、表日、文件校验和版本见 PACKAGE-MANIFEST.json。Excel 是分红业务日、档位、合约代码和点数的值表，可离线打开。较新行情通过「一键补齐收盘」补齐。

Python 与账号

内置 Python 3.13.17 64 位及锁定的离线依赖，直接启动即可。要复用同事已有 Python，双击「Python环境设置.vbs」，浏览选择 python.exe，点「检查环境」或「一键补齐依赖」，再保存启动。补齐只安装到看板自己的依赖目录，不改同事原来的 Python。64 位 Python 3.13 可以用随包 wheel 离线补齐。其他兼容版本需要能访问该 Python 配置的 pip 源。可点击「切回内置 Python」恢复。确切依赖版本见 PACKAGE-MANIFEST.json。

账号和密码在当前 Windows 用户下加密保存，分发时请使用原始 ZIP。自动数据 VPN 使用已配置网关和本机可用的公司 VPN 客户端。出现验证码或二次认证时，请在公司客户端操作。需要 Wind 查询的功能请使用已安装、已登录且有授权的本机 Wind 环境；高级设置可以单独选择 WindPy 的 Python。

使用提示

盘前显示最近已完成交易日的收盘参考。随包历史、实时行情与公盘分红日期分别展示。默认临期门槛为 1 个自然日，可在数据更新页修改。图表的坐标轴窗口和分位计算窗口可分别设置。

启动异常时，请先用「Python环境设置.vbs」检查，确认本地解压目录可写。也可以在「数据更新 / 设置」点「导出诊断」。
