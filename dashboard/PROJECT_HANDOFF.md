## 当前指标口径及 0% 问题

F 为期货价、S 为对应指数价、D 为分红点数、T 为具体合约到期剩余自然日。

- 分红调整基差点数 `F - S + D`；基差 bp 为 `10000 * (F - S + D) / S`。
- 简单年化百分数为 `100 * (F - S + D) / S * 365 / T`；T < 5 的日子不参加年化历史样本。
- 首页按当前连续档位回看历史；T 取每个历史日实际映射合约到期日；固定 D 情景把当前具体合约 D 用于整段比较，不声称是真实历史分红。
- 20 日窗口先取定位日之前 20 个交易日，再按年化适用性筛选；不是必然具有 20 个年化有效样本。另有 3/6/12 自然月窗口。
- 分位为 `100 * (小于当前值的样本数 + 0.5 * 等于当前值的样本数) / 有效样本数`。
- 覆盖不足、有效样本少于 2、无有效当前报价等原因与合法 0% 应区分；允许部分缺日的连续窗口必须显示缺日和有效 n。零方差不是自动缺失。

用户新反馈：IF 的实时 20 日基差年化分位显示 0。本轮只记录，尚未冻结该时刻、档位与样本进行诊断。0% 可能为合法尾部分位，也可能涉及样本/映射/缓存/显示问题；不得先断言无误或把 0 自动改为 NaN。下一轮须独立复算并导出逐日证据。
