## 资料差异的处理

1. Word 的 A03 边界段将前收与开盘条件概括在一起；JSON 明确 `intra` 只依赖开盘及当前价格。实现按 JSON 分别判定，缺前收不会清空独立有效的盘中变化。
2. JSON 某些日终事件说明写“完整 240 根”，坐标也给出了本次样例的 240 根。按本次用户要求，240 只用于该样例；运行完整性由会话配置生成的预期网格决定。可通过现有配置中的 `indicator_v6_sessions` 指定已确认会话，未配置时使用规范中的两段会话。
3. JSON 通用参数字典把 q 同时用于持仓占比与股息率。A10 的界面明确为股息年利率，不套用容量参数名称。
4. 对未知原因的历史归档 null，应用扩展原因 `ARCHIVE_REASON_UNKNOWN`，中文明确“具体原因尚未定位”。这是展示契约扩展，不推断成预热、零权重或期限错误。

其余核心公式、单位和样例未发现数值冲突。原始归档、Word、JSON 均未被改写。

## 验证及边界

执行 `python -m dashboard.indicator_v6.test_core` 可在无真实行情的公司检出中执行全部 12 个 JSON 边界案例。`test_v6` 在本机原始资料齐备时进一步核对 157 次真实样例字段比较、242 个日坐标、240 个分钟坐标、逐日年化改变历史排序、固定期限 l/ac 的统计一致性、换月断线及独立有效输出。缺资料时明确跳过真实数据回放测试，不用合成数据代替。

`validate_ui` 离屏验证 Qt 控件、图例、悬浮内容、公式和 1100/1440 宽度。`validate_browser.cjs` 在隔离无头浏览器核对三组数量、切换与缓存、有效零、午休接缝、悬浮信息及 1440/1100/768/390 宽度；截图保存在本机 `outputs/2026-10-23/app_v6_validation/`，不提交。

当前已发布日频服务的本机观测截至 2026-10-16；研究日频回放截至 2026-10-14，完整分钟样例为 2026-10-09。都按实际时间标注，不标实时。公开代码不包含真实回放文件；公司优先读取原配置的已发布数据，回放资料未安装时明确提示。

尚未开放年化差分回归：规范要求显式给出新单位下的解释变量方差与残差阈值，当前未配置，不能套用小数收益阈值。C03 年化还原分支支持 β=1；β≠1 的归因由两腿原始序列计算。当前 32 项按规范默认窗口和情景计算，未开放任意参数编辑。跨指数当前提供 IF/IC 同到期组合；A 与 B 可选择现有合法具体合约及同品种合约对。

分钟回归 / 波动 / 确认只使用已完成同步分钟，不使用盘中轮询报价冒充分钟 bar。现有分钟输入缺少的日期或合约按依赖留空；所选日的日终确认可由该日分钟重算，其他日确认只有已完成归档可用时展示。分钟与日线成交口径不强行调平。公司实时接口和现场效果仍需现场验证，本轮未连接真实 VPN 或实时公司接口。
