## 当前功能

1. **PySide6 Qt Widgets 原生桌面 App**。入口 `start.cmd` 或 `python -m script_making`，依赖 PySide6-Essentials 和 openpyxl；双击由 pythonw 启动独立窗口。默认无浏览器/WebView/HTTP 监听。公司沿用 `swhy_delta1` 环境，缺少依赖时运行 `install.cmd`。
2. 默认读取「存续合约估值」和「簿记要素」，工作表和历史报表日期可选；Sheet 查询参数保留接口。
3. App「数据与同步」可填写路径或用原生文件夹选择器修改共享来源、本地保存目录。设置保存在忽略的 `config.local.json`，立即生效，已有文件不搬移；沿用旧版本配置。HTTP 接口通过 `python -m script_making.app` 按需单独启动，继续提供 GET/POST `/api/settings`。
4. 后台同步按北京时间选择早于今日的最新日期目录，依赖上游按交易日生成。两份文件不齐则停止，不静默回退；45 秒超时，失败保留本地查询。
5. 复制前后检查源文件稳定性、工作表、大小和 SHA256；按日期记录 `manifest.json`。不覆盖同名不同内容文件，支持手动导入。
6. 文本支持顺序简称、连续包含、OR 备选词、AND 组合；「证投」可匹配「证券投资」。数值支持范围、比较及可配置的绝对 ε（默认 1e-8），零和空值分开。提供日期范围、排序、分页、显示列及全部字段详情。
7. 读取实际有值或公式的 XML 边界，跳过纯格式导致的虚假 104 万行范围。读取缓存值，不重新计算公式。
8. 每个列条件先选内容格式：文本、数字、日期。默认采用识别结果，但允许手动覆盖；切换格式清空该条件的旧操作和输入。数字可解析文本金额、千分位、百分号，非数值和空值不计作零；数字编号也可按文本搜索。API 条件新增可选 `value_type`，不修改原表和列元数据。
9. 后台线程读取和查询；过期查询结果丢弃，切换条件立即清空旧结果。复制同步使用独立进程，45 秒超时。退出等待正在执行的任务结束。原生多选、Ctrl+C 原始值复制、表头排序、分页、列选择和双击全部字段详情已实现。窗口大小与显示列仅写入忽略的 `ui.local.ini`。
