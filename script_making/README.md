## 2026-10-21 必须 / 任一条件组合与单个值复制

每条筛选条件新增「必须 AND / 任一 OR」选择，默认必须。查询规则为 **所有必须条件成立，并且任一条件中至少一条成立**；没有任一条件时仅检查必须条件。例如交易对手设为必须，合约编号和数量各设为任一，即 `交易对手匹配 AND (合约编号匹配 OR 数量匹配)`。所有任一条件组成同一组，暂不支持多组嵌套括号。空白输入不参与筛选，明确选择「为空 / 不为空 / 近似零 / 非零」仍是有效条件；全字段搜索也必须满足。

结果表和双击打开的详情中，右键所需值选择「复制此单元格」，或单击该值后点「复制单元格」/ 按 **Ctrl+Shift+C**。复制原始值且不带列名，保留文本编号的前导零、长数字和完整数值。**Ctrl+C** 和「复制选中行」保留整行及列名复制；更换筛选或结果后须重新选择，避免复制旧结果。

## 搜索和筛选

- 每个条件按「必须 / 任一 → 选择列 → 内容格式 → 条件与数值」操作。格式默认采用列识别结果，可手动选「文本」「数字」「日期」；每个条件独立解释，同一列也可添加不同格式的条件。
- 选择「数字」可对文本保存的金额、含千分位或百分号的值按数字筛选；不能转换为数值的内容与空值不计作零。选择「文本」可对数字编号进行包含或简称搜索。手动日期格式采用 `YYYY-MM-DD`，无效日期不匹配。
- 更换列或内容格式会重置该条件的操作与输入，避免沿用不兼容的条件；不会改写 Excel，也不会改变其他条件的格式。
- 默认「模糊匹配」支持连续子串和顺序简称。例如「申万」「证投」均可匹配「申万宏源证券投资总部」。
- `/`、逗号、竖线分隔同一文本条件的可选词（OR），空格分隔同时需要的词（AND）。跨列或使用不同操作时，每条选「必须 AND」或「任一 OR」：所有必须条件同时满足，所有任一条件组成一组并至少满足一条。空白输入忽略，全字段搜索仍是附加的必须条件。
- 可改用连续包含、精确等于、不等于、为空、不为空。
- 数值列提供范围、大小比较、近似等于、近似零和非零。支持科学计数法、千分位和百分号；`5%` 表示原始数值 `0.05`。
- 默认绝对容差 `ε = 1e-8`，窗口中可临时调整，在设置中保存默认值。`|x| ≤ ε` 为近似零，`|x| > ε` 为非零，空值不计作零。
- 范围采用 `min - ε ≤ x ≤ max + ε`；大于为 `x > value + ε`，大于等于为 `x ≥ value - ε`。小于对称处理。
- 日期格式提供日期区间。支持表头排序、分页、显示列和双击查看全部字段详情，详情显示 Excel 原始行号。拖动表头边缘可调列宽。
- 右键单元格选择「复制此单元格」，或单击值后点「复制单元格」/ 按 Ctrl+Shift+C，可复制不带列名的单个原始值，详情窗口同样支持。Ctrl / Shift 多选当前页记录，Ctrl+C 复制选中行的可见列与列名，复制使用原始值。窗口大小及每个工作表的显示列保存在 `ui.local.ini`。更换筛选、日期、页码或工作表会清除当前表格选择；持久化开平计划尚未实现。
- 读取 Excel 保存的缓存值，不调用 Wind 或重新计算公式。使用原始小数筛选，显示格式不影响比较。

| `POST /api/sync` | 请求体 `{}`，开始后台同步 |
| `GET /api/sync` | 查询 `idle/running/success/error` |
| `GET /api/sheets?kind=swap&date=2026-10-14` | 可用工作表 |
| `POST /api/query` | 查询、排序、分页，返回字段类型及 Excel 行号 |
| `POST /api/import` | 二进制 Excel，`X-Filename` 为 URL 编码后的原文件名 |

JSON 请求使用 `Content-Type: application/json`。`kind` 为 `swap` 或 `review`。不传 `sheet` 时使用默认工作表。列 ID 从查询响应的 `columns` 获取，不能依赖任意列名对应固定位置。

```json
{
  "kind": "swap",
  "date": "2026-10-14",
  "sheet": "存续合约估值",
  "filters": [
    {"column": "c2", "value_type": "text", "op": "fuzzy", "value": "证投"},
    {"column": "c14", "value_type": "number", "op": "range", "min": "5000", "max": "10000"}
  ],
  "epsilon": 1e-8,
  "sort": {"column": "c14", "direction": "desc"},
  "page": 1,
  "page_size": 50
}
```

`value_type` 可选 `text/number/date`；省略时采用原识别类型，兼容旧请求。每个条件的 `join` 可选 `must/any`，省略为 `must`；规则为 `all(must) AND (无有效 any 或 any(any))`，最后与 `search` 同时满足。空白值和双端空白范围忽略，显式 `blank/not_blank/zero/nonzero` 不忽略。文本操作：`fuzzy/contains/eq/ne/blank/not_blank`。数值：`range/gt/gte/lt/lte/eq/ne/zero/nonzero/blank/not_blank`。日期：`range/eq/gte/lte/blank/not_blank`。`search` 为全字段关键词，每页最多 200 条，最多 30 个条件。错误返回 HTTP 400 和错误信息，跨站访问返回 403。
