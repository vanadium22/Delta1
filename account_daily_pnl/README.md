# 三账户场内持仓与盈亏

## 首次配置日更

1. 在公司 Git 根目录执行 `git pull --ff-only`。已经跑通单日测试的，可直接复用原数据目录里的历史 Excel。如果尚未导入历史，把 `account_daily_pnl_history.zip` 放到项目目录，与启动文件同级。
2. 登录 Wind，接通可访问 BCT 的公司网络，双击 **setup-daily.cmd**。首次会复用本机已有 BCT 设置或下载脚本，找不到时弹窗选择原来的 `download_trading_flow_add_holdexcel.py`、`download_trading_flow.py` 或附件原始 `1.zip`。程序验证登录后，用当前 Windows 用户加密保存凭据。
3. 会在已有的 **工作自动化工作台 → 定时子任务** 登记「三账户场内持仓与盈亏」，默认北京时间周一至周五 **09:35**，开启错过后自动补跑，并立即试跑前一交易日。已登记的任务沿用原时间和启停。在工作台的任务详情可查看计划和运行日志。

日常由工作台后台启动 `start.cmd`。公司电脑保持工作台后台、Wind 登录及 BCT 网络可用即可。需要手动催跑时双击 **start.cmd**。计划或网络中断后，程序下次成功运行按交易日补下载和重算。若目标日盈亏仍有缺项，会先保留 Excel，在日志和工作台状态显示待补。

结果默认在仓库根目录 `outputs/account_daily_pnl/`，包含 `场内账户_交易日.xlsx`、`逐交易日统计.xlsx` 和两张收益图。

工作台路径非默认时，从仓库根目录执行 `.\account_daily_pnl\setup-daily.cmd --work-root "工作台目录"`。已有工作台任务的时间可直接在「定时子任务」编辑。正式总权益需要公司结算权益和已核实的入出金，见下文报表口径。

## 公司只测一天

1. 在公司 Git 根目录执行 `git pull --ff-only`。
2. 把单独交付的 `account_daily_pnl_history.zip` 放到本目录，与 `test-yesterday.cmd` 同级。首次运行会核验并导入到本机的 `data/account_daily_pnl`。已下载文件按哈希复用。
3. 打开本机 Wind 终端并确认已登录。双击 **test-yesterday.cmd**。它回放基准以来的持仓，只导出前一个交易日的报表。默认报表位置为仓库根目录的 `outputs/account_daily_pnl/场内账户_YYYY-MM-DD.xlsx`。窗口会显示日期、回放进度和保存位置，按键后关闭。

本次历史包截止 2026-11-18。以后要复测该日，可以在本目录执行 `.\test-yesterday.cmd --date 2026-11-18`。使用 11 月 18 日包测试 11 月 18 日时，BCT 流水和快照均可本地读取，Wind 用于缺少的前一交易日价格。若测试日超过数据包截止日，则按以下日更方式增量下载。

启动入口复用公司已有的 `swhy_delta1` Python（默认 `D:\conda\envs\swhy_delta1\python.exe`），窗口首行显示实际解释器路径。程序依赖 requests、openpyxl 和时区数据。首次从原始 ZIP 直接导入旧版 XLS 时还需要 xlrd。如果 WindPy 装在另一 Python 里，把 `config.example.json` 复制到数据目录的 `inputs/config.local.json`，填写本机的 `wind_python` 解释器路径。

## 正式日更和中断补跑

- 双击 **start.cmd** 执行常规日更。可供公司计划任务调用的命令为 `start.cmd --no-pause`。需要下载 BCT 时，将本机已有可信 BCT 脚本路径配置到 `inputs/config.local.json` 的 `bct_script`，或用 `BCT_CREDENTIALS_SCRIPT` 环境变量指向脚本。也可使用本机环境变量 `BCT_USERNAME` 和 `BCT_PASSWORD`。凭据直接交给 BCT 登录，无需放进数据包。
- 以北京时间取当天之前最近的交易日。程序从基准起核对交易流水存档，缺几天补几天。历史快照只补已结束月份的最后交易日。正常日更自最近成功下载日恢复，停跑期间遗漏的交易日逐日下载快照、流水和生成报表。节假日和周末按 [交易日历](../dashboard/marketdata/trading_calendar.py) 跳过。
- `flows/`、`snapshots/`、`wind/` 分别保存按业务日命名的原始流水、BCT 快照和 Wind 缺价补录 Excel。BCT 的账簿和日期从接口校验，分页核对 `totalCount`。无成交的交易日保留有表头和零行元数据的有效流水文件。下载中断后，下一次运行复用已保存文件，继续缺项。源归档和正式报表逐文件原子写入。
- 全量日更会更新每天的明细、`逐交易日统计.xlsx`、`历史至今_账户收益.png` 和目标年份的收益 PNG。统计表含「收益概览」「逐交易日统计」「今年逐日」，图片含三个账户与合计的单日、累计净盈亏。图表使用公司已有的 QtGui。缺行情时曲线留断点，区间的盈亏和费用覆盖日数在 Excel 中查看。
- 需要指定统计日时，从仓库根目录运行 `python -m account_daily_pnl --date YYYY-MM-DD`。`--only-day` 只写该天报表，累计收益率由全量日更生成。`--prepare` 只准备输入 Excel，`--no-download` 和 `--no-wind` 用于离线核验。

## 报表口径

| 内容 | 计算 |
| --- | --- |
| 持仓 | 从 2025-12-29 日终滚动，2602 使用 BCT 5102 组合、5526 使用基准、5524 从空持仓起算。期货用买卖方向加开平记多空两边。送转入数量，现金分红入盈亏。 |
| 单日净盈亏 | 前后两日有结算单权益且资金流水已核对时，采用当日总权益 − 上日总权益 − 当日净入金。其余交易日用成交估值净盈亏。报表单列权益法盈亏、成交估值费前和净盈亏、当日手续费及结算权益差与成交估值的对账差额。 |
| 成交估值 | 今日日终净持仓价值减前一交易日日终净持仓价值，加卖出成交额、减买入成交额、加现金分红、减手续费。期货同一合约用相同乘数。隔夜仓以昨结为当日起点，新开仓按成交价与今结之差，同日开平按卖价与买价之差。现金分红与送转按流水业务日入账。 |
| 手续费 | 优先逐笔累计原始 `fee`，缺值时用可核对的费前、费后金额反推。结算权益已计入手续费，成交估值扣一次原始手续费。 |
| 价格 | BCT `instrumentQuote` 优先，缺项按实际交易日向 Wind 查询。默认现货为 `close`，期货为 `settle`，核对公司 BCT 估值口径后可用 `wind_futures_field` 改为 `close`。跨来源的期货价格会提示核对。 |
| 总权益 | 优先使用结算单总权益。也可用确认的基准权益 + 累计净入金 + 成交估值累计净盈亏推算，并标为模型权益。每账户填 `opening_equity` 及 `cash_flows_confirmed_through`（已核对入出金的截至日）。通过 `cash_movements` 列入实际归属交易日 `date`、`account`、`net_deposit`，出金用负数。 |
| 参考权益 | 基准表中的基金净值或本机配置值，加已登记资金流和计算盈亏，在资金覆盖或基准权益待确认时提供参考。5524 空仓不代表期初资金为零。 |
| 收益率 | 当日净盈亏除以上日总权益与按时间加权的外部资金合计。资金明细可填 `weight` 作为当日在账时间比例，开盘前到账填 1，收盘后到账填 0。时点未知的资金变动日及依赖该日的区间收益率留空。逐日收益率按几何连乘，今年按目标日所属年份重置。 |
| 累计净盈亏 | 历史从基准日收盘起算，今年以前一年最后一个交易日日终为起点。两个区间端点的结算权益和资金流水都齐全时，用扣除区间净入金的权益变化。其余情况用同口径的成交估值端点。 |

要导入结算权益，在数据目录 `inputs/账户总权益.xlsx` 的第一个工作表提供「交易日」「账户」「总权益」三列。账户填 2602、5526 或 5524，同账户同交易日一行。基准日和报告日均可录入。入出金和覆盖日期从 `inputs/config.local.json` 读取。

表内的期货名义额用于查看敞口。BCT 持仓快照按交易簿归集，报表的「数据检查」使用三个账户的净持仓与账簿快照对照，差异保留供核对。
