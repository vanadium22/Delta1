# Delta1 桌面应用

使用 CustomTkinter / Tk 构建独立桌面窗口。桌面入口直接调用 Python 采集服务，无需浏览器、HTTP 服务或前端构建步骤。

## 启动

Windows 双击上一级的 `index_strategy/start_app.cmd`。启动器使用本机统一环境目录中的 `P:\code_content\python_work_env\conda_env\swhy_delta1\pythonw.exe`，不会自动开始采集。

也可在仓库根目录运行：

```powershell
conda activate swhy_delta1
python -s -m index_strategy.desktop
```

新电脑先按照 [环境说明](../env/README.md) 建立环境。环境位置不同，可设置 `SWHY_DELTA1_PYTHON` 为该环境中 `pythonw.exe` 的完整路径；或激活自己的环境后使用上述模块命令。Windows 启动器失败时显示说明；Python 启动错误会弹窗，并记录到 Git 忽略的 `localsetting/desktop_error.log`。

## 使用

1. 在左侧选择「数据下载 → 实时下载」。交易数据下载目前为预留页面。
2. 修改标的列表：每行一个代码，也支持 JSON / Python 字面量 list。可用系统文件窗口多选导入 `.json`、`.txt`、`.list`，与编辑区合并、统一大写并去重；也可导出 JSON list。
3. 填写采集间隔，单位为秒，支持 `0.5` 等正小数。选择数据保存文件夹，也可直接填写路径；相对路径按仓库根目录解析。
4. 「保存配置」供下次打开恢复；「开始采集」会先校验并保存配置，再启动后台采集。需要公司内网或 VPN。
5. 右侧上方为整体运行表：时间、成功/部分失败/失败、失败标的及情况说明，选择一行可查看说明。下方为行情 DataFrame 表：默认第一个标的，可随时用下拉框切换；显示秒级采集时间、最新价、累计成交量、区间成交量和买卖一档价量、接口行情时间。表格可横向和纵向滚动。
6. 整体表最多显示 400 行，行情表最多显示所选标的最近 200 行；显示缓存总量有上限，完整历史保存在数据目录。清空记录只清上方显示，不删除磁盘数据；关闭自动滚动可查阅旧记录。
7. 点击「停止采集」后，等待当前请求完成或超时、剩余数据发布为 Parquet，再恢复编辑和启动按钮。采集期间配置锁定，修改后需重新开始。关窗也会先停止并保存，界面继续响应，完成后自动退出。

导入是读取文件当时的内容，不持续关联源文件。桌面配置保存在 `localsetting/realtime_ui.json`，每个应用实例写入独立的 `localsetting/realtime_symbols_<实例编号>.json`，避免多个窗口互改运行标的。与早期网页配置兼容；同一数据目录的第二个写入任务会被文件锁拒绝。程序启动后不会自动恢复未结束的任务。

## 数据格式

行情格式为 **Parquet**，每行一个标的一次有效采样，保留最新成交价、累计及区间成交量、五档买卖价量、采集时间和接口时间。默认路径是 `Z:\Project_data\realtime_market\data\标的\年\月\日期.内容哈希.parquet`。首批、每分钟以及停止时归档，单日可有多个互不重叠的增量分片。

每批采样都会立即提交到 `live/quotes.sqlite3`，策略通过只读 DataFrame 接口读取，无需等 Parquet 归档。策略结果有独立目录，不与行情文件共写。详见 [字段与策略读取说明](../instant_dld/README.md)。

接口只提供时分秒，采集时间与真实行情时间分别展示，不能把采集时间当作交易所成交时间。盘口缺档或接口占位价格会保留为空，不伪造五档。配置、数据、错误日志均被 Git 忽略。

## 验证

```powershell
python -s -m unittest discover -s tests -v
```

桌面测试使用真实 GUI 控件、临时目录与模拟请求，覆盖配置恢复、多文件导入、目录选择、开始/停止、关窗等待、后台异常及导航。需要可用的 Tk 显示环境；无显示服务器的 Linux CI 可使用 xvfb，缺少 GUI 环境时桌面测试会明确跳过。
