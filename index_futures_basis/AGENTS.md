# 股指基差 App 的持续开发约定

作用范围：本目录 `index_futures_basis/`。这是与券单模块并列的 Python + PySide6 原生桌面应用，入口 `python -m index_futures_basis`。

1. 开始先读 `PROJECT_HANDOFF.md`、`README.md` 和相关实现；用 `git rev-parse --show-toplevel` 确认根目录，再检查当前分支、最新提交、Git 状态。以实际版本为准，不回退，不覆盖未提交工作。
2. 按用户2026-10-19长期要求，本模块与所有App的开发、更新、提交及推送统一使用 `codex/company-apps`，不再建立或使用独立模块开发分支。优先复用统一分支的现有工作目录，保留旧目录未提交内容；业务范围仍按当前需求，不无故改造其他模块。Git命令见 [Git操作指南](../Git操作指南.md)。
3. 保留已确认的 IF/IC/IM/IH、00—03 连续档位、实际合约到期日、分红加回价格、临期仅作图填充、自然月统计、同到期日 IM−IC、换月持仓计算等口径。60/90日固定期限先插值基差率再年化，每品种一条曲线；02−00、03−02跨期年化以现货为分母、两实际到期日间隔为期限，禁止直接相减单合约年化。60/90日固定期限、单档、跨期与IM−IC分位默认3/6/12自然月，均排除当日。按用户要求，图片及Word/计算CSV的窗口按类别独立保存并可修改，查询保持默认窗口；窗口需进入计算缓存、图名/图注/文字、表格和来源清单，禁止用较短历史冒充完整窗口。业务歧义需要说明；普通界面细节自行判断。
4. 行情持久化到本地，默认仅补日历/映射/到期日/日期/实际代码/字段的缺口。普通查询、绘图和CSV只读本地；正式Word默认尝试增量更新，北京时间15:05后纳入当天。按用户2026-10-16最新要求，Wind超时、断开或缺数时使用本地可用数据尽力导出，不再限定仅回退前一交易日或因不完整停止；图表缺失部分断线/留空，不能填零或将旧行情冒充今日。另保留“仅用本地生成Word”入口和CLI --local-only，完全跳过Wind。注明实际来源、各品种最新日期、缺失及失败原因；指定截止日保持不变。离线/演示不联网，真实导出禁止回退到演示。强制重取已有数据必须走明确日期范围，不改回每次全量下载。
5. 分红来自用户最新 Excel，不自动猜零，不改为未经确认的 Wind 预测；按表内日期选择，记录文件哈希。保留正式、离线、合成演示隔离和来源追溯，不能用演示冒充真实数据。
   按2026-10-16要求，图片与查询可独立选择分红调整后/不调整分红，默认调整后；未调整用F−S、F远−F近重算全部衍生图和分位，完全不读取分红，图内/文件名/清单标识。加回值0只表示用户选择不调整，原始分红列留空。Word及报告页CSV保持原分红口径，不能被图片选项隐式改变。本地股指数据页仅读原始close/oi及映射/到期日，不依赖分红或四品种完整，F5不得触发下载。
