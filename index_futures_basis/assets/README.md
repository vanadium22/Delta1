# 报告样式模板

`report_template.docx` 从用户原报告版式提取，保留 A4、宋体、正文/图注/表格样式、页边距及页脚页码。正文、表格、行情图片、批注和自定义 XML 已移除；页眉为空，缩略图为空白，作者等身份元数据清空。

版式参考原文件 SHA256：`706b4e97c55b50429ed991895bb3cd1eecdcdc29c6a04920027c48428db70fd9`。原参考文件未修改，不需要随 App 分发。

生成报告由 `report.py` 填充。模板只提供样式，不包含真实行情或用户分红数据。

## 桌面快捷方式图标

- `app.ico`：Windows 多尺寸图标（16、20、24、32、40、48、64、128、256 px，透明背景）。
- `app.svg`：可编辑矢量源；蓝色双曲线表示期货与现货之间的基差。
- `app.png`：256 px 透明预览。

在公司双击项目根目录 `create_desktop_shortcut.cmd`，即生成「Delta1 股指基差」桌面快捷方式并自动设置图标。图标由各项目随 Git 同步；不要移动或删除 ICO，项目搬家后重运行创建脚本。
