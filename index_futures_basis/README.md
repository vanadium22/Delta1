## 公司桌面快捷方式（2026-10-16）

公司保持 `codex/company-apps`，在仓库根目录 `git pull --ff-only` 后，双击本目录 **`create_desktop_shortcut.cmd`**。它会在公司当前用户的实际桌面创建 **「Delta1 股指基差」** 快捷方式，并自动使用 `assets/app.ico`，无需手动更换图标。只在需要快捷方式的电脑执行；无需新建 Python 环境或管理员权限。

快捷方式通过 Windows CMD 运行本目录现有的 `start.cmd`，沿用其正式模式及解释器选择。路径取自运行脚本所在目录，没有写死家里或公司的盘符；桌面位置使用 Windows 系统配置，兼容重定向桌面。正常启动后控制台随现有 `start.cmd` 结束，报错仍按原入口显示。

移动项目目录后，从新位置再次运行创建脚本即可更新同名快捷方式。若同名快捷方式属于其他程序，脚本报错并保留它；先自行重命名原快捷方式后再创建。不要把创建脚本单独复制到桌面，也不要删除或移动项目内的 `assets/app.ico`。生成的 `.lnk` 包含该电脑的绝对路径，不通过 Git 分发。

需要把快捷方式先生成到指定文件夹时，可在 CMD 使用：

```bat
create_desktop_shortcut.cmd -OutputDirectory "D:\Shortcuts"
```

`-NoPause` 可用于自动化检查。创建过程只依赖 Windows PowerShell 和 WScript.Shell，不启动 App、不读取业务数据；公司若限制 PowerShell/脚本宿主，需按公司策略处理。本机已验证生成、回读、重复更新、中文及特殊字符路径与模拟 CMD 启动，公司实际桌面及策略尚未实测。

## 平时怎么用

1. 登录 Wind，双击 `start.cmd`。先读本地行情，正式模式默认随后检查并补齐缺口。
2. 新分红 Excel 放进 **仓库根目录的 `data/dividends/index_futures/inputs`**，文件名为 `基差情况_日期.xlsx` 或 `指数基差情况_日期.xlsx`；也可点「导入分红 Excel」。查询和导出会自动重读。
3. 在「基差查询」选择品种、00—03 档位、指标。默认就是 **IC → 03 最远月 → 分红调整后年化基差**，一次显示 3、6、12 个自然月的均值、中位数、当前百分位和分位点，可复制进 Excel 或导出 CSV。
4. 「图表浏览」可只生成一张 PNG，也可生成全部 46 张图；支持缩放、复制、另存。「报告与记录」生成完整 Word（42图、15表）或导出 13 类计算数据 CSV，双击记录打开目录。

IH上证50已与IF、IC、IM并列加入同步、查询、计算明细和各类图表。升级后启动检查、F5或生成正式Word会增量补齐IH历史映射、实际到期日、收盘/OI和上证50现货；已有其他品种有效数据继续复用。分红表须含IH00—IH03的G列点数。行情或分红缺失会明确报错；旧三品种离线快照需补齐IH后重新导入，演示模式会自动更新合成样本。IM−IC专项图仍按原配对定义计算。

新增固定期限与跨期分析：

- IF、IC、IM、IH各使用自身00—03四档实际合约插值，每个品种得到一条60日或90日固定期限曲线。60日、90日各提供近3个月和近1个月的四品种比较图。
- 60日、90日固定期限各有独立分位图，默认显示此前3个月、6个月、12个月的当前百分位和分布；图内标出当前值、当前百分位和有效样本数，Word各列汇总表。
- 各品种02−00、03−02分别提供近3个月跨期年化曲线、当前值、3个月/6个月/12个月分位图及汇总表。四品种分位图采用2×2子图和独立纵轴，标明当前百分位和样本数。
- 「基差查询」指标包含60/90天固定期限、02−00跨期年化、03−02跨期年化。固定期限及固定跨期组合自动禁用档位选择，选择品种后即可查询；查询统一使用3/6/12个月，与默认图表和报告一致，不随图片或Word的自定义窗口改变。
- CSV包含`fixed_60d_quantiles`、`fixed_90d`、`fixed_90d_quantiles`、`calendar_annualized`、`calendar_annualized_quantiles`。固定期限逐日记录插值两端合约、天数和权重；跨期逐日记录实际配对、到期日间隔、现货分母、原始价差和分红差，便于复核。

### 自定义时间窗口

- 「图表浏览 → 图片时间窗口」按类别分别设置：常规时序、60日曲线的两个窗口、90日曲线的两个窗口、跨期曲线，以及单合约/60日/90日/跨期/IM−IC的分位窗口。曲线月份范围1—36；固定期限曲线填写两个不同月份，分位填写1—3个不同月份，用逗号分隔，按自然月计算。
- 默认常规和跨期曲线为3个月，60/90日曲线各为3个月和1个月，各类分位均为3/6/12个月。更改后立即用于下一次生成，图表名称、日期范围、当前分位和样本数同步更新；已生成的图片保留原日期和窗口。
- 「报告与记录 → 报告时间窗口」独立设置Word及全部计算CSV的窗口。只改图片窗口不会改变Word；不修改时Word采用上述默认值，可随时恢复默认。报告中的标题、说明、表格和数据CSV随报告窗口一致变化。
- 设置保存在本机配置的`chart_windows`和`report_windows`，演示配置单独保存。加长窗口后，下一次启动检查、F5或正式Word会按更长范围只补历史缺口；单独绘图不联网。时序历史不足会明确拒绝绘制，分位历史不足显示“覆盖不足”，不以已有短窗口冒充完整历史。

**正式模式生成 Word 前自动检查并补齐行情，随后校验交易日历、实际映射、到期日和全部行情字段。** 默认北京时间 **15:05** 后尝试当天；更新未成功时使用前一交易日，并在界面弹窗、Word首页和导出清单注明实际日期与失败原因。前一交易日也不完整则停止生成，不继续寻找更早日期。手工指定历史截止日时保持所选日期，缺失就提示补齐，不自动改期。

普通查询、绘图和CSV只读本地；也可通过启动检查或F5更新。离线/演示导出不调用Wind。停留在应用内不会定时轮询，点击正式Word生成会重新检查。

Word最前面列出实际行情日期、报告生成时间、分红快照日期，以及IF/IC/IM/IH各档的期货收盘价、现货收盘值、实际合约、到期日、剩余自然日、分红、调整基差和年化值。正式报告注明生成前的校验结果；发生回退时加粗显示目标日期、实际日期和原因。核对他人结果时先统一行情日期；生成日期和分红表日期均不等于行情日期。年化显示3位小数，计算仍使用原始精度，临期不足5天仍留空。

## 本地增量更新

- 首次同步建立中金所交易日历、IF/IC/IM/IH 的 00—03 历史实际合约映射、实际到期日、期货 `close/oi` 和对应现货指数 `close`（IH为`000016.SH`）。默认下载 12 个月外加 15 天缓冲，供自然月统计和日变化计算使用。
- 原始记录保存到 仓库根目录的 `data/market/index_futures/wind/market.sqlite`，以日期、实际代码、字段判断缺口。缺口可以在历史中间，不能只看最大日期向后追加。日历、映射、到期日也分别缓存。
- 同一范围完整时再次检查是 **0 次 Wind 请求**；有新交易日只取新数据，单个字段缺失只补该字段。旧历史不随窗口滚动删除。基础历史窗口可在设置中调为12—36个月；实际增量检查范围取基础历史、图片窗口、报告窗口的最大值，再加15天缓冲。
- 请求按连续缺失交易日分段，成功批次立即入库；中断后保留，下次续补。错误、空值、非法价格/OI 不会当零写入，也不用前值填行情。同步记录显示请求批数、错误和未完成缺口。
- 日线默认在北京时间 **15:05** 后包含当天，之前取上一自然日，再依交易日历确定实际截止日。周末、节假日采用最近交易日，不误报更新失败。时间门槛不保证数据商已发布全部字段，仍须逐项校验。
- 旧版默认18:00配置会自动迁移为15:05；原有其它自定义时间保留。设置页可精确到分钟，保存后重新打开生效。迁移不改行情库或历史数据。
- 正常增量同步不自动识别 Wind 对已存历史的修订。确认需要修订时使用「重取指定日期」，重新获取该范围映射和行情；其它缺口仍补齐。失败响应不会覆盖原有效值。
- 同一行情库只有一个写入任务；查询读取也避开另一个窗口正在更新的过程。SQLite 请放本机磁盘，不建议把运行中的数据库放网络共享目录。

## 分红和统计口径

| 项目 | 口径 |
| --- | --- |
| 品种 | IF 沪深300、IC 中证500、IM 中证1000、IH 上证50 |
| 连续档位 | 00 当月、01 次月、02 随后第一个季月、03 随后第二个季月；03 是最远月，剩余期限不是固定半年 |
| 绝对基差 | `期货收盘价 + G列分红点数 − 现货指数收盘值`，保留正负号，非取绝对值 |
| 年化基差 | `绝对基差 / 现货收盘值 × 365 / 剩余自然日 × 100%`；剩余不足 5 天留空 |
| 临期画线 | 仅同一实际合约内沿用最近有效年化值画横线；换月重置。填充值不进入统计、表格、分位图或数据原值 |
| 统计窗口 | 单档、60/90日固定期限、跨期及IM−IC分位默认使用截止日前3、6、12个自然月；图片和Word可独立自定义。左闭右开，不含截止日；历史按每日实际映射计算，不把今天实际合约强行外推 |
| 当前百分位 | `(小于当前值的历史样本数 + 0.5×等于当前值的样本数) / 有效样本数 × 100` |
| 蜡烛图 | 实体 P25—P75，中位线 P50，上下须 P5—P95，红菱形当前值；各档纵轴独立，保留较高画幅 |
| 缺失处理 | 行情内部缺口拒绝计算；历史长度不足的窗口标记覆盖不足，均值/分位留空。临期年化、新挂牌缺少前日持仓、无法包围60/90天的插值是数学不可用值，不作零样本；有插值合约但缺输入不得当成数学不可用而剔除 |
| 持仓变化 | 同一实际合约相对上一交易日的变化，换月不把不同合约持仓相减；品种总持仓变化另按四档总和 |
| 跨期价差 | 各品种 01、02、03 的分红调整后期货价格分别减 00 |
| IM−IC | 两边各自调整后的绝对基差相减，校验同日同档实际到期日一致；单位指数点，不等于两期货价格直接相减 |
| 60/90 天固定期限 | 四档中选包围目标天数T的相邻合约，`b(T)=w×b近+(1−w)×b远`，`w=(D远−T)/(D远−D近)`，`b=(F+G−S)/S`；再以`b(T)×365/T×100%`年化。排除剩余不足5天的合约；无法包围时留空，不外推 |
| 02−00、03−02跨期年化 | `[(F远+G远)−(F近+G近)]/S ×365/(D远−D近)×100%`，S是同日现货收盘值，期限为实际到期日自然日间隔；不是两档各自年化基差相减。近月不足5天仍按真实价差计算，不用画线填充值；换月改变实际配对 |

分红读取 `Sheet1!B1` 的表内日期、B 列连续代码、**G 列分红点数**。不用文件名日期或文件修改时间排名，不用 J 列。保留所有历史表格也可以，自动选表内日期最新者；同日优先主目录，同目录同日内容冲突则报错，Excel 的 `~$` 临时锁文件忽略。公式必须已在 Excel 计算并保存；无公式缓存的空白不当零。

G 列是**本次固定分红假设，应用于整个连续档位历史窗口**，不代表历史逐日可得预测，也不向 Wind 下载分红。切换行情截止日仍使用当前最新 Excel。每次查询/导出重新读取 Excel 内容及 SHA256，变化后重新计算，旧报告保留。

首次升级会复制原 `inputs/input` 和旧研究分红目录到公共分红目录，校验哈希并保留原件；完成后仅扫描公共目录或显式自定义目录。以后请使用「导入分红 Excel」或放入公共目录。无可用分红时，仍能同步原始行情，但不能生成调整后的统计和报告。

## 数据、文件与模式

```text
仓库根目录/
  index_futures_basis/             # 源码、启动入口、本机正式配置
  data/market/index_futures/wind/market.sqlite
  data/market/index_futures/offline/market.sqlite
  data/dividends/index_futures/inputs/
  data/dividends/index_futures/archive/
  data/demo/index_futures_basis/   # 合成行情、独立演示配置
  outputs/index_futures_basis/<模式>/<行情日>/<批次>/
```

三种模式完全分库、分导出目录。演示模式始终使用合成行情/分红，图片与 Word 有标识，不访问 Wind，也不使用正式配置。离线导入支持原项目的 `raw_market.json` 或包含 `trade_date,root,slot,instrument_id,expiry_date,futures_close,spot_close,open_interest` 的 CSV；验证通过后替换离线库，正式库不受影响。离线的交易日覆盖依导入文件声明，不能替代 Wind 校验交易日历。

导出清单 `run_manifest.json` 记录实际行情日、分红表日期/路径/哈希、原始数据哈希、计算代码哈希、文件哈希、模式及`configuration.windows`中的实际窗口。窗口参与计算版本指纹；自定义窗口的导出不会标成与默认查询一致。导出会保留本次分红 Excel。已有图片显示其自己的日期、窗口与版本，不会因设置或新 Excel 更新而被原地改写。原研究输出也可在离线模式的记录页打开。

模板 `assets/report_template.docx` 只保留原报告的 A4、字体、页边距和页脚版式，已移除正文及旧图。代码不依赖券单 App 或旧研究目录；旧分红目录只参与首次复制迁移；旧输出仍可在记录页查阅。旧研究命令不改动，其全量下载方式也不会自动变成新 App 的增量模式。

## 命令行与开发

在仓库根目录，使用配置好的 `swhy_delta1\python.exe`：

```powershell
python -X utf8 -m index_futures_basis
python -X utf8 -m index_futures_basis --demo
python -X utf8 -m index_futures_basis --diagnose
python -X utf8 -m index_futures_basis --sync
python -X utf8 -m index_futures_basis --export report
python -X utf8 -m index_futures_basis --mode offline --import-snapshot "原报告目录\raw_market.json"
python -X utf8 -m unittest discover -s index_futures_basis/tests -t . -v
```

`--sync` 只同步后退出，成功退出码0、部分完成2、异常1；正式模式`--export report`自动先更新校验，回退时在终端明确输出原因，日期和更新记录保存在`run_manifest.json`的`market_update_check`中。图片/CSV仍只从本地导出。`--diagnose`检查当前解释器依赖，不连接Wind。不要加`-s`，否则可能屏蔽用户目录里已安装的WindPy。公司与家中环境的实际验证边界见交接文档。
