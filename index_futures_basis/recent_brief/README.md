# 基差简报子项目

在仓库根目录使用已有 Python 环境运行：

```powershell
python -X utf8 -m index_futures_basis.recent_brief
```

也可运行上一级 `start_recent_brief.cmd`，使用原项目已有的解释器设置。不修改原工作台。

默认只读配置对应的本地真实行情库，取其中最新可用的一库，不联网、不拼接行情库、不使用合成演示。输出保存在 `index_futures_basis/exports/recent_brief/行情日/批次/`；打开 `index.html` 即可查看四张合并图片及图下短说明，图片可独立使用。

1. 近期绝对基差与跨期：左侧四指数各00—03，右侧各01−02、02−03；默认最近60个本地交易日，换月有标记。
2. 单合约年化与60日分位：每品种一行，左侧合并00—03四条年化基差曲线，右侧同一坐标系放四根蜡烛；走势和蜡烛共用本行纵轴（%），不再拆为24个小格。须P5—P95、实体P25—P75、中线P50，红菱形旁为当前实际年化值，横轴附百分位及有效样本数。
3. 跨期年化与60日分位：每品种左侧仅01−02/02−03两条曲线，右侧两根蜡烛，合并成一张四品种总览。
4. 四合约总成交与总持仓：四个品种面板，每个面板将00—03四合约相加，总成交用柱形（左轴），总持仓用曲线（右轴），单位均为万手。任一合约缺值，对应总量留空；明细仍见CSV。

2026-11-17 最新版采用纵向加高的3800像素宽、200dpi PNG，另存可放大的SVG。每品种上方自动生成指标卡：当前值、1日/5日基差点数或年化bp变化、60日百分位及分位日变；量仓卡显示总量、绝对/相对变化和20交易日放量倍数。最近5日阴影、加粗线和深色成交柱直观显示近期变化，空心点是5日前、实心点是当前。当前红菱形位于对应蜡烛中心，数值标注自动限制在绘图区内，布局校验另存`.layout.json`。为使临期极值和其他曲线都可见，单合约走势/蜡烛中00读蓝色右轴、01—03读左轴，各自标清刻度，不能跨轴按高度比较。

绝对基差仍为去除分红影响的 `F+G−S`（期货价加回剩余分红点数后减现货），保留正负号。单合约年化为 `基差/S×365/剩余自然日×100%`。跨期按图中文字直接做 **前者减后者**：`01−02=(F01+G01)−(F02+G02)`、`02−03=(F02+G02)−(F03+G03)`；跨期年化再除以同日现货，乘365并除以两实际到期日的自然日间隔，不相减两腿各自年化。这是本简报的独立配对，不改变原工作台远减近的跨期图。

沿用原项目分红Excel的选择、日期和G列口径，固定快照应用于全部连续档位历史，明确不是逐日历史分红预测；不可用时调整后指标留空。用户已确认“60日”为**此前60个交易日历史窗口**，不是60天固定期限，也不是60个自然日；当日排除，并列值半权重。按用户最新要求，本子项目单合约**T≥1全部计算、绘图、生成分位与卡片，T=0留空**，不再沿用旧版T<5过滤或虚线填值；完整覆盖60个交易日后排除已知T=0样本，未知到期日/缺输入/未知日历不得被丢弃而冒充完整。原工作台/Word的独立规则不受本子项目改变。日/5日点数和年化变化按连续档位计算，换月标记；分位日变为“今日自己的60日窗口排名−上一交易日自己的60日窗口排名”，单位为百分点（pct），年化1bp=0.01个百分点。各合约持仓日变仍按同实际合约比较，总持仓日变为四合约总量之差。观察项采用年化60日5%/95%尾部及四合约总成交相对前20交易日中位数的2倍阈值（至少10个有效样本）。

如果本地共享数据已有 `dashboard/normalized/backfilled_cn_index_future` 或 `cn_index_future`，默认从一个冻结版本中按交易日+实际合约补充最近80个交易日的成交量；校验清单和分片哈希，要求单位为手，不从该数据集替换期现货价格或持仓。不依赖看板代码，只有使用Parquet补量时需要环境已有的 `pyarrow`。

```powershell
# 指定原项目已有的四品种真实快照，不覆盖原行情库
python -X utf8 -m index_futures_basis.recent_brief --snapshot index_futures_basis/data/qa/real_20261015/raw_market.json

# 指定日期、分红与输出；日期缺数据时留空，禁止旧收盘冒充指定日
python -X utf8 -m index_futures_basis.recent_brief --as-of 2026-10-15 --dividends "D:/资料/基差情况.xlsx" --output "D:/简报/20261015_01"

# 完全不读取额外成交量数据集
python -X utf8 -m index_futures_basis.recent_brief --no-volume-supplement

# 自动模式：每60秒检查本地行情/分红/成交量版本，有变化才生成；Ctrl+C退出
python -X utf8 -m index_futures_basis.recent_brief --watch

# 指定输入与自动输出根目录，持续监控这些输入；不会下载新行情
python -X utf8 -m index_futures_basis.recent_brief --watch --snapshot "D:/资料/raw_market.json" --dividends "D:/资料/基差情况.xlsx" --output "D:/简报/自动生成"
```

也可双击上一级 `start_recent_brief_watch.cmd`，沿用原项目的Python配置。运行期间监控SQLite及WAL、分红文件、新增分红表和成交量current版本；每次变化生成新批次，不覆盖旧报告。固定入口 `exports/recent_brief/latest.html` 指向最近成功结果（显式单次`--output`时在其父目录；自动模式指定`--output`时作为自动输出根目录）。`automation_state.json`记录生成/等待/失败状态；失败不更新成功批次指针，latest页说明未更新成功，输入变化后重试。输入不变不会反复绘图。自动模式只监控本地文件，原数据更新程序负责下载行情；本项目不会自动启动Wind或修改系统计划任务。

同目录另存逐日基差、逐日跨期、两类**年化60交易日分位**、最新合约、总量及量仓观察CSV，另有`basis_cards/calendar_cards/activity_cards.csv`和`cards.json`可复核卡片。`run_manifest.json`版本3保存实际截止日、各品种最新日期、行情哈希/来源、成交量冻结版本及逐分片哈希、分红路径/哈希、年化公式、交易日窗口、T≥1、总量及变化口径、渲染参数、观察阈值、代码及输出哈希。旧版本批次独立保留，不混称窗口或临期规则。真实输入、导出均不提交Git。

首版预览使用已核验四品种快照（2026-10-15）和2026-09-18分红，成交量来自本地已存修订后日线；生成日为2026-11-17，不能将预览称作11月最新行情。
